# 单库有限模式穷举（事后，2026-11-15，零API）

在已看到完整历史复验中calculator页的init失败、并检查六库公开模式之后选择本项：原calculator/GPT-5库的六个可选字段只有枚举字符串和布尔值，包含省略字段共有(2+1)(2+1)(4+1)(2+1)^3=1215个JSON对象配置。这是有意选择可穷举的单库诊断，不是随机基线、预注册主实验或六库的代表性抽样。旧库、模式、编译器、页面及成绩不修改，不调用模型。

逐字段列出全部合法值及省略，笛卡尔积枚举；不固定原模型方案的字符串、布尔值或字段存在性。对象按模式字段顺序规范表示，讨论JSON对象的语义配置，不计空白和键顺序为新配置。冻结编译器直接读取这六个命名字段并形成固定模板，不按输入键顺序分派。所有1215方案经原封闭模式验证和原编译入口编译；按全部输出文件逐字去重，编译失败仍留档。任何浏览器评分前冻结全集、方案到源码的对应关系、运行器及测试。

端点只用官方calculator的init.spec.js，包含初始布局和基础计算断言，不只是截图或布局。完整历史指标包含此文件，故init全过是完整历史的必要条件；init通过不充分证明任何更长历史通过。每个不同源码执行一次，Playwright1.57/Chromium、原30s/5s超时、零retry、单工作浏览器、max-failures=1，至多四页并行。先在同一运行器上验证官方最终参考页通过、空白页失败，随后执行所有候选，保留每个报告。旧观察不参与择优复用或重跑。

如果全部配置都存在决定性断言失败，结论限于此冻结库、完整模式、当前测试/运行环境及init必要条件；不能称所有GUI行为不可实现、原当前文件任务不可达、另五库不可达或形式化验证。若出现通过配置，原样报告其数量，不扩展搜索或改变端点。全局运行器错误/缺失报告与模型行为失败分开，不能计作不可达证据；时限内未完成则只报告完成子集。
