# 单一JSON代码块的事后格式诊断

此诊断在看到两份Sonnet响应带前导说明、但尚未开始任何本阶段候选行为评分时追加。它不是初始预定实验；主实验仍严格执行原解析器及原库回退，原记录不改写。

动机是区分输出包装失败与实现修复效果。对主实验已接受的库原样复用；对被拒响应，只允许提取**唯一一个**独占行标记的JSON（或无语言标记）代码块，然后使用相同JSON解析、字段白名单、原接口及例子编译验证。不得改代码、拼接多个块、补括号、参考成绩挑选块、追加API响应。无法恢复时保持主实验的原库回退。

全部12份响应完成后，将提取规则、源码、提取结果、包和600项比较输入一并冻结，再开始新评分。使用与主实验相同的180个旧候选、固定最终页和开发检查。按完整文件映射、项目及任务共享原始评分；无需重复运行相同页。单独报告严格格式结果和提取诊断，不能择优替换主结果。此诊断最多说明同一响应经透明格式规范化后的行为，不证明严格契约已满足，也不是新规划结果。
