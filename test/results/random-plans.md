# 随机方案基线：随机选变体能过多少任务（零 API，`uv run python -m test.random_plans`）

变体槽位的每一种取法都编译并用官方测试评分；非变体部分（工具按钮、菜单、快捷键、开关、钩子）取按规范写出的参考方案。「通过概率」= 穷举完成后通过取法数 / 全部取法数。它是固定正确菜单/钩子条件下的概率，不是整个方案语言的均匀随机基线。TodoMVC 遇到首个反例即停止，其余测试未执行，不报告测试级均分。
