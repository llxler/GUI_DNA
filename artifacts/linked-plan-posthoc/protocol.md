# 离线事后修复：按启用功能连接计划

本修复在读取第二轮全部隐藏成绩后提出，因此结果只用于问题诊断和工程回归，不是独立确认性实验。原始 264 个候选及成绩不修改，不新增模型请求。

公开编译反馈显示，大量模型计划包含已知但未启用的函数或事件。原编译器要求精确集合，因而在浏览器运行前拒绝；自由 JavaScript 对照则允许定义未被调用的函数。新连接器只去除已知未启用事件及行变换，其余交给原编译器验证。未知节点、错误绑定、缺失必要功能、启用阶段重复、错误顺序及遗漏页码规范化仍然失败；不自动补全正确计划。功能集合来自公开任务需求，不读取隐藏数据、操作或答案。

对主实验 compiled 与补充 compact_plan 的全部 48 个已保存候选，固定使用各自首次响应及原修复预算结束时的最终响应，不择优、不再修复。先写出全部连接后的页面和编译诊断，冻结后统一运行原公开与隐藏检查，分别报告行为、状态及基础保留。相同候选的首次/最终代码相同时可复用评测。累计模型调用和费用不变，原先的失败生成与修复成本仍需计入，不能将此重放当成一次新模型采样或零成本生成。

对照仍为原 DNA、预加载函数的 linked_dna、同上下文的 compact_js，以及 100% 的确定性计划参照。即使修复达到 100%，也不证明模型规划优于确定性构造或最强基线。未来若开展确认性研究，应在新任务与独立数据上预先固定本接口。
