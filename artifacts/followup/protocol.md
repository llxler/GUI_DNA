# 第二轮预先固定的探索协议

本轮在看到第一轮结果后设计，不是对第一轮假设的独立确认。开始付费生成前固定此协议、源代码、数据种子、函数库和配置；隐藏结果不用于生成或调参。

主要改进：将完整 deriveView 拆成纯行变换及分页函数，所有库方法共享同一原子代码；增加受检查的组合计划编译，固定函数体，校验事件覆盖、选择器无状态写入、先过滤/排序后分页、每次事件后按匹配总量校正页码。编译器的这些领域规则是方法的一部分，不是形式化证明。库是人工重构，不声称本轮自动学习了新抽象。

比较 direct、retrieval、dna、metadata（仅说明）、checks（仅检查）、constrained（说明＋检查）、compiled（说明＋检查＋模型计划编译），另加 deterministic（已知功能直接映射计划，无模型调用）。八组均用相同 HTML 框架、公共需求和公共操作序列；后四种有附加契约检查，metadata 没有检查。所有模型方法输出上限 5000 tokens，初次生成＋最多两轮修复。编译计划可达到同样行为所需输出更短，这是被测机制的效率收益，而非提高输出上限。

六种新组合：搜索/筛选/分页；编辑/筛选/分页；编辑/排序/删除/撤销；搜索/筛选/排序/编辑/分页；筛选/编辑/删除/撤销/分页；全部七功能。采用 DeepSeek V4 Pro 0813（DeepInfra）和 Qwen3 Coder Plus（Alibaba），每任务两次采样。计划 24 个完整八方法组，168 个模型候选、24 个确定性参照。新模型在本任务中是否更好需要测量，不由厂商描述代替。

隐藏测试使用新数据、三个固定种子的长交错序列、不同页长、非默认筛选/排序初始值、空列表，以及适用时的删空后恢复。原始 16 个开发任务和全部 6 个新任务的参考编译结果先做离线校准；新数据及操作轨迹不会放进提示词。公开检查与隐藏检查均以真实 DOM 操作执行；空撤销额外使用事件接口验证幂等性。

主指标：首次候选和最终候选的隐藏可见行为通过率，全部序列通过才计成功。辅指标：基础功能保留、内部规范状态合规、初始化成功、可运行、修复次数、输出 tokens、费用、生成耗时。内部状态差异不直接扣主行为分；页面显示、编辑草稿和撤销按钮等可见差异仍扣分。初始及最终候选均在全部生成冻结后评估；不选择隐藏表现更好的版本。

主要比较 compiled 相对 dna 和 constrained 的逐任务配对胜/负/平，以及固定预算下的成本。若准确率相同而费用或修复减少，只称效率改进，不称准确率提高。若 deterministic 与模型方法持平，要明确说明该有限功能域可能无需模型规划；不能把确定性编译的收益写成语言模型能力提高。若强基线仍满分，保留负结果，不继续改同一隐藏测试直到出现优势。

所有旧费用、未知费用预留和新调用共用 artifacts/budget.sqlite3。累计硬上限 $9，新增预留达到 $8.8 限制时停发；HTTP 429 每次重试独立预留，未知收费不清零。发生预算或接口错误停止扩展，完整组用于主表，部分组保存但不进入主表。

费用资料在开始时通过 OpenRouter models/endpoints API 保存于同目录。DeepSeek V4 Pro 0813 $1.3/$2.6 每百万输入/输出 token，Qwen3 Coder Plus 短上下文 $0.65/$3.25；路由强制价格上限、禁止 fallback。原第一轮源码归档 artifacts/v1-source.tar.gz（SHA256 e70383c70e6f6165af5e1ee809515da6b1620459ea513fa4e733b716f85c1555），原始结果不覆盖。

付费前校准修订：长序列暴露共享 shell 中草稿 onchange 在失焦时重绘行节点、吞掉下一次删除点击的问题。文本和数值草稿统一改为 oninput，类别仍为 onchange；所有方法使用同一修复。失败参考校准保存在 calibration-before-input-fix/。这是参考实现执行发现的框架修复，尚无模型候选或隐藏模型结果参与调参。另对相同搜索值显式触发输入事件，以使测试事件语义确定。

服务可用性调整：第一组 Qwen 完成后，Claude 指定路由的七个请求均返回 HTTP 403；Gemini 3.1 Pro 探测明确返回地区限制。DeepSeek V4 Pro 0813 原厂路由受账户数据使用规则过滤，未更改该规则，改用通过连通测试的 DeepInfra 路由。以 DeepSeek V4 Pro 0813 替代 Claude；旧失败运行完整归档 followup-unavailable-claude/。没有读取或使用这段中断运行的隐藏成绩。复用 Qwen 已结算响应，其有效提示、模型参数、种子、函数库和候选不变；每次重放都核对模型和完整上下文。接口失败收费无法确认时仍保留预留。
