# 原样重放首份已交付的更新程序

这是对四份已被拒收的 Flash 程序进行的事后诊断。首轮方案均由真实预算账本记录。只取每站第一次交付的 program，不尝试第二次或挑选结果。保留原严格协议的全部失败。

程序与出处说明分别验收。出处引用不精确时保留原引用并逐条标记，不让它阻止重放有效的可执行程序。显示文字可含普通货币符号，仍禁用标签和表达式。布尔值的非正数下限对 false/true 都成立，移除这种恒真门槛并留痕，其他操作、变量、数值、标签、页面内容均原样使用。程序其余字段不能根据判分修正。比较活动和惰性双页。三个预定新站报告所有官方操作；已见游戏页另作一次更新前后的资源核对。主表不使用该事后结果。生成不需 API。复评另开 $1.30 账本；此前生成和已结束复评的敞口加上仍在运行的两项判官上限及新上限必须低于 $20。
