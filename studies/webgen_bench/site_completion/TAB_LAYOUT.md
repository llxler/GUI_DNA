# SDK 标签栏与视觉判官

在旧游戏页上，人工组件实现能显示按金钱排序的五行排名，但原判官没有打开排名页。初始视口宽 1024 像素，排名入口中心在视口外，第一页的 WebVoyager 元素未给它分配编号。此处只改一个上游 SDK 原生属性 tabsMode=vertical，保留整份原配置、表格行、处理函数、视口和数据不变。局部开发试验已证实旧页的排名标签能进入视口。

在新批次全部 27 份封存的人工库页面上，独立统计初始视口能获得 WebVoyager 编号的实际标签数，逐页面列出有无损失。此统计只需公开页面和浏览器，不读任务列表。旧游戏排名另对水平和垂直两个版本用同一已校准主判官各重放一次，保留原始 NO 和两次重放结果。该病例因已知判官漏找而选，不能估计全基准提升，亦不改变主表端点。新判分账本最高 $0.40，纳入当轮总上限。
