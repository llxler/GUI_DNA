# 全部九站统一修正人工 SDK 标签栏

这是对已登记的九站实验另立的展示协议，行为目标和分母规则保持一致。原因来自旧游戏页的确定性重放和新页面的首屏检查。完整的 204 个标签中，原 SDK 布局只能给 158 个分配首屏编号；使用 SDK 自带的纵向标签后，27 页的 204 个都能被编号。该控件设置只改变标签位置。原先登记的横向布局主终点保留在 judgments.json，不回填。
