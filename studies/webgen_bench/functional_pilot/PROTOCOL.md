# WebGen-Bench 六站同题功能实验

使用父协议预先抽定的六站、三个目标模型及全部 43 项操作。先封存候选，再由独立进程读取操作及预期。一个网站只生成一次，多个检查在独立浏览器会话内复用它。Direct 仅读单站公开网站需求并输出一个可离线运行的 HTML 文档。库工作流共享同一套不携带站点内容的声明式接口以及每个模型、每站的一份原配置。模型自行选择标签页、内容、表格、输入、表单、详情对话框与动作。接口限制到局部状态，不提供服务器或外部服务。界面语言由生成器自行选择。三个流程各可作一次公开格式修复。

Human 使用百度开源团队的 amis 6.13.0 SDK 原样渲染及交互，本研究只实现约束和加载绑定，原开发人时未知。版本及 NPM 发布摘要保存在登记中。Self 使用同一目标模型写兼容渲染器，再由该模型配置。GPT-5 单独请求真实 GPT-5 撰写同一接口的库，三款目标生成器配置同一份。四个 AI 建库者各看六站的公开生成需求和研究者事先定义的接口示例，本阶段每个建库者构建一份跨站共享的库。逐组编写模块；公共准入检查在独立的示例中要求能切换标签页、点开详情并提交一个简单表单。本地判定结果可供同模型修正一次。冻结所有首次建成、未建成和传输缺失的结果，不用官方操作反馈改动候选。除张贴公开说明的注册信息和字段外，候选生成器不接触评估操作、预期、截图或测试轨迹。

使用三个目标模型六站所有候选的同一冻结批次。优先注册基准作者的 Qwen2.5-VL-32B-Instruct 评估模型。如果登记时该型号无可用路由，原版评分保留缺测，并单独披露替代评判。替代视觉模型为 Qwen3-VL-30B-A3B-Instruct，使用官方任务指令、标号截图和动作语法，浏览器驱动适配到本地 Playwright。限定候选本机来源，初始视口 1024×768，每项最多 15 次交互，最多三张截图，保留每次模型决定和轨迹。将最终明确的 YES、PARTIAL、NO 分开，依原论文分别计 1、0.5、0 分。无返回、判分未完成不推定为否；逐行四种方法仅按同一检查 ID 比较，并另标总覆盖。每臂覆盖全部已登记操作才允许发布 43 为分母的结果。公开合成校准只测试评估器，不计入数据库。在真实任务之前用有状态开关与无效果按钮做正负对照，校准失败或评判不足时如实标出。官方模型及替代评判各自注明。不同评估器分开保存和展示。
