# WebGen-Bench 可移植组件接口与按内容填表

本协议在检查首批模型响应与公开样例、观察正式评估样本的判分前制定。保留原始六站、三个模型、18 份从零回执与所有原流程记录。新配置协议让每款目标模型针对每站填写一次站点内容结构，把模型给出的标签、文字、命名字段、真实数据、表头、弹窗内容与表单反馈绑定到已有 amis 组件；模型自主决定各站内容与操作。字段在所有站点相同，编译器不读取网站编号、网站任务、评分操作或预期，不实现业务逻辑。模型可按公开的格式错误修一次。对全部模型/网站统一采用本预定的新协议，即使旧成绩更高。保留旧 Direct 及其真正的无效输出；两种部署协议费用与信息不同，按模型披露。

初次 Gemma 把 DocumentFragment 当成可设置 display 的元素。Qwen 对单个子节点调用 forEach，并从模块内部递归调用自己的局部渲染器，从而绕过其他模块。提供给三个 Self 库的兼容接口一致：body 字段可变为节点列表，列表渲染返回普通容器，在声明函数内部使用 AST 将未被局部遮蔽的两参数 renderNode(child,ctx) 子节点请求路由到共享分派器；样式、事件、表格、表单仍来自原建库者。若原库已通过公开场景，原样使用。否则按固定顺序尝试形状转换，在公开样例合格后停止。未合格时给同一建库模型反馈真实浏览器异常，以及实际子元素文本，依次对布局、记录、输入、表单、操作各最多修一次；仅保留公开检查无回退且有新增，收录所有失败。Human 仍运行百度 amis 6.13.0 原二进制。因 403 的原模型另外保留真实 GPT-5 可得性的回执，缺测不做替代。所有候选封存后启动相同的替代视觉评判协议；字节和部署环境均相同的候选直接引用上阶段已冻结的原判分和支出，不重复制造证据。预登记对六站、43 项全部检查，即使结果不理想也不采择。此阶段建库/生成预算 1 美元；前阶段的实际费用及未决承诺保留。判分共享此前 6.80 美元授权的剩余额度，另开账本但从上限扣除已用及正在承诺的敞口，不允许两账本合计超过同一判分上限。截止时间 11:55 UTC。
