# 空网页与第二评判模型

对冻结六站的所有 43 项操作，用相同的 Qwen3-VL-30B 视觉评判器、截图、指令和动作协议测试没有内容的起始页。再独立验证部分完成的判分方式，合成页面上两个独立目标有且仅有一个可以达成。结果都单列；不给任何建库或规划程序看这些操作、预期或判断。

在查看候选成绩前，对每个网站按 SHA256("webgen-rater-v1:" + site + ":" + zero_based_check) 最小值取一项，共六项。使用同系列早一代、更大的 Qwen2.5-VL-72B-Instruct 对新配置协议下各模型、各来源的这些页面重新操作，不提供首评的分数或历史轨迹。先用既有独立开关正负场景校准 72B。若服务不可达或未能分清开关，保留缺失与校准原件，判分者之间的比较留空。准确报告真正完成的成对判断数、完全一致率及各方向的不一致；无效网站的启动失败单列。主表仍用先登记的 30B 真实结果。本诊断新增敞口最多 2 美元，且以实时额度为限，11:55 UTC 停止。不同账本单独核对。基准作者指定的 32B 仍单列。
