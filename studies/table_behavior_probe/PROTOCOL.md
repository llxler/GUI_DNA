# Web-Bench table 的单字段行为干预

本诊断只使用已冻结的两套 table 库和公开需求。分别检验 task-2 的右键删行和 task-8 的 Delete 清除当前选中单元格。两个操作和观察规则在读取库选项、运行候选前固定。无模型调用，不读取或修改官方断言、历史隐藏成绩或目标候选。

对每位建库者分别取两个文档示例，再从第一个示例出发，逐个将不同的顶层字段替换为第二个示例的值（含新增与移除）。保留无效配置。每个不同的编译页面启动两轮浏览器测量；每个操作及其对照都在全新上下文中进行。两轮用于检查可重复性。参考页与空白页先校准。

删行操作在首个 tbody 单元格右键后单击公开的删除菜单项，对照在右键后按 Escape。读取操作前后各行内容，目标结果为恰好删除第一行且其余各行相同。清空操作在首个正文单元格左击后按 Delete，对照按 Shift；成功须恰好清空原有非空内容，其他单元格和行不变。表格或初始内容不可观察记为缺失。控件不可用、操作无效或对照改变表格均不记成功。两轮均可观察且方向一致、一处顶层字段替换在两轮均改变一个目标的通过状态，才记为该库的行为见证。单个顶层字段可能包含多个设置，结论只限这次干预。未观察到见证不能证明整个模式不可表达。
