# canvas 的独立模型复验

沿用首个匹配项目 canvas 与 32,000-token 协议，在前面三批 GPT-5 运行结算后另作一批。预先固定同一个替代模型 Claude Sonnet 4.5 同时承担每种工作流的准备及目标生成。选择原先首个匹配项目和旧研究中另一位建库者；项目与模型均无需根据本阶段成绩选择。该复验是看到 GPT-5 小试后的跟进。重复 1、2 各有一次独立准备和五个独立目标，沿用相同任务、资产、系统提示、静态运行时、公开检查、一次修复及当次最后输出。使用 OpenRouter 的 Anthropic 供应商路由，关闭额外推理，temperature 0.6，不传 seed；支出及推理机制因模型而异。只在两流程使用相同模型的行内做比较。

预算固定为 $3.00/重复/流程，四组最高 $12。只有此前三批所有账本的新请求阈值已关闭、已用和预留加 $12 未超当天 $20，且查实有效余额至少 $12 时启动。沿用 13:30 UTC 新请求截止。全部工作流冻结后按相同的五个当前任务文件独立评分。校准沿用相同测试与参考页的原始报告。保留所有失败和缺失；若存在缺失，报告双方共同可观察的位置与各自缺失数。使用相同位置分别计算成功数，不作跨模型或跨项目合并。沿用已固定的 canvas 行为检查和固定页控制，没有额外模型调用。
