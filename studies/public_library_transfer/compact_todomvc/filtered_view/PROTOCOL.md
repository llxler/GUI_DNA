# 筛选后的列表与整个应用的状态

冻结逐开关实验的八题配置、两款小模型各两份库、原 Direct、Human 和 GPT-5。之前的公开状态样例已经显示有控制器按当前可见项计算页脚。此研究只替换 select(state)，将显示列表与所有事项的统计分别说明。研究者给出接口和公开状态样例；整个函数仍由原模型生成。注册五个训练状态，覆盖混合状态和空筛选。每个模型每份库至多一次基于这些状态的修复。选用第一个正确返回全部七个字段并通过原五个公开状态的函数。否则保留原件。先封存两套逐题页与两套固定全开页，再用三组不同的事项、筛选和编辑状态检查函数，并在八个正式目标上评分。配置输出缺失及无效照录。升降均采用这次预设的第一库，公布全部重复和固定页。三个新状态、之前的编辑措辞探针和八个同题成绩分别报告。仅 B 的同题开发，本研究没有独立的新官方目标。
