# 编辑动作与保存范围

对 Gemma 3 4B、Ministral 3B 已经通过公开检查的两份 TodoMVC 库分别验证。八个原任务是开发集；本轮知道旧成绩。唯一改变的是配置输入输出。给部署模型公开需求、每个开关能阻止的具体操作，以及动作、持久化、显示三种范围。模型抄出禁令并选择范围。仅在原文可查、模型明确判为禁止当前动作且指明合法开关时关闭。未被禁止的能力默认保留。禁止存储和禁止显示都没有权限关掉动作。结构不合法算无效，传输缺失算缺测。控制器、固定页和三个其余方法沿用原候选及评分。

冻结两组三句话，各组分别要求允许编辑、禁止编辑、禁止保存编辑状态。独立浏览器上下文新建已命名事项，调用编辑，刷新真实页面，核对同一事项仍在、编辑入口和临时状态；固定全开页同时检验判据。六项新探针只作机制检查，不加进八题分母。先封存全部配置再评分；本轮主表用每模型第一库，不按成绩选择新旧配置或两次建库，涨跌一并报告。另报第二库与全开页。完整覆盖无变化也保留。禁止把正式断言、得分、题号和探针判决放进生成提示。
