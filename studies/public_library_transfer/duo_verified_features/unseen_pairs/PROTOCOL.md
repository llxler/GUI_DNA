# 两个域的新功能组合，独立确认

原十个配对的 Flash Direct 过 9/10，唯一剩余题与锁定运行器的查询参数匹配不一致。本批独立比较 Flash 从零、Flash 自建及真正 GPT-5 建库交给 Flash 配置。沿用固定版本，与主表原样本分开报告，无论结果好坏。博客与任务管理域分别排除原 15 个功能及已用异组合捐赠源码中的全部附带功能。仅按文件名排除；不读取候选组合的评分、难度、断言或发布生成物。对每域余下官方组合，按 SHA-256("gui-dna-duo-novel-20261128-v1/"+域+"/"+组合名) 升序取前五。冻结十题、公共功能来源及评分文件哈希，再生成源码。此独立性限于本研究的样本与调试；模型训练语料未知。

每个建库者仅看一个组成该目标的公开单功能文件，使用上一阶段的单文件 React 接口，首次公开两例全过的源码入库，最多三次交付，均未全过保留首份可执行源码并标注。真正从零组由 Flash 面向每个目标一次写两个功能，给相同的单功能公开材料，原样挂载同一页面分别在两份公开单功能测试上检查，最多两次纠正；使用首次在两者同时全过的代码，均未全过沿用首份可执行代码。禁止引入测试设施、修改评分或复制被测组合实现；生成时不看组合判决。Flash 为两种库共享同一批配置，另以域内固定前二原样复用。每份源码和每一项配置先封存；随后评分全部十题，每题原四个用例全部通过才计 1。单功能例与双功能断言可能重合；这是开发后对新功能组合的复验。主表的六款模型仍保留原共同分母。独立预算 2.45 美元，与此前三个付费账本的额度合计 9.95 美元，整轮上限 10 美元、截至 15:05 UTC。
