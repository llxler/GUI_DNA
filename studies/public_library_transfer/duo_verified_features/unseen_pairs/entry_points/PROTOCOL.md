# 官方导入入口的配对复算

在独立十题的审计中，三份上游 Jest 测试的唯一相对导入名与题目文件名不同。原样按题名提交页面时，Jest 未能载入这三个套件的任一用例。本阶段对首次和真实路由适配两批封存候选、全部方法与固定对照应用同一交付规则。读取官方文件中唯一的同目录模块导入；其名称与题名不一致时，加入一个只重新导出该原始候选默认组件的入口。此前以题名为入口的页面字节、模型配置、资源、依赖和评分文件全部固定。同名任务复用既有报告，并核对上游文件散列。新增入口清单、候选字节摘要和两批方法的配对关系一起冻结后才评分。逐行要求官方四个用例均有实际判决。首次成绩和随后在同题修正路由的成绩分列；先前不能载入的套件另列，不按模型能力计分。无新增模型调用。
