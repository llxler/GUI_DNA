# 有来源的表单 SDK 对照

上游没有可追溯的人工功能实现。本阶段检验独立人工维护的 Final Form 5.0.0 和 React Final Form 7.0.0，两者原样从带 SHA-512 完整性字段的 npm 发布包取得。该 Human 属于第三方 SDK 对照。作者没有交付这十五个业务功能的参考代码。SDK 管理字段值、提交流程、异步成功与失败状态；研究者的通用宿主负责挂载、HTTP 传输和响应字段显示；目标模型只填写每个公开单功能的有限 JSON 配置。仓库不把研究者或模型写的绑定计作人工功能实现。模型只能填字段、可访问名称、可选值、初值、动作、相对 URL、请求映射、消息和结果字段。禁止提交 JavaScript 或模拟响应。逐功能支持手动提交和页面初载；每个已配置动作必须发真实请求。公共校准使用另一种表单和接口，分别交付 201、409 并检查收到的非示例输入。

全部六款目标模型都独立做同一份公开的十五项功能绑定，首次不满足两项公开检查时允许一次同模型重写，第一份两项全过的配置进入库；没有全过则保留最后一次可执行的配置并记录真实失分。域内须有至少一个已经公开验收的功能才能计分。部署使用原作者补建阶段冻结的同一批目标模型选择，与 Direct、GPT-5 和 Self 使用同一行实际题号。固定头两个功能另测，公开名称控制另测。封存所有选择与页面后使用原 Jest 原四例。首次独立预算上限 2.5 美元，之前阶段最高 4 美元，整轮 10 美元内，统一截止 2026-11-28 15:05 UTC。结果注明建库来源和模型配置成本。
