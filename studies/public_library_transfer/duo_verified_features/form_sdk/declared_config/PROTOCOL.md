# 接收实际交付的有限配置

部分小模型在 JSON 前后附有解释，第一版整答解析把有效配置记为缺失。本阶段只补上一阶段没有可执行配置的单功能。先按原请求顺序检查原始回复；在 Markdown JSON 围栏中必须恰有一份可通过原配置校验的对象。相同 JSON 可去重，同时出现两份不同配置则拒绝；不从部分对象拼接。保留早期全部原始失败。若两次都未交付，向同一模型按原公开单功能和相同语法再请求最多两次。明确只要数据；不允许增加可执行脚本。第一份可执行的配置参加公开验收，若公开两例未全过可以用剩余一次机会请求修正。接受先前已可执行的配置，无论其成绩。所有目标共用原模型先前的选配和未改动的 SDK；先封存配置和候选，再跑同一原文件。新账本最多 1 美元，前三阶段总上限 7.5 美元，整轮 10 美元。各账本统一截止 15:05 UTC。
