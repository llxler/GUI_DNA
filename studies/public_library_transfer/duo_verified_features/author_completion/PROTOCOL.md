# 原作者补齐不足的单功能组件

基于已封存的公开单项检查进行增量建库。六款 Self 只用本模型旧源码；GPT-5 只用基准作者发布的 GPT-5 异组合源码和 openai/gpt-5 的实际新答复。每个仍未通过两项公开检查、或没有模块的功能，向原模型提供该单功能的独立公开操作、公开 HTTP 契约与原组件（若有），请求完整可挂载的 React 模块。使用时间先后的第一份两项全过回复，公开失败最多允许两次独立修正。明确禁止导入测试设施、发出额外无意义请求和自行改变 API 的参数。报告边界有已确认的查询参数冲突，仍保留原组合和分母，对报告功能只提交一次准确实现，存档公开失败。原端点若明确拒绝后停止此模型的新建库，已验收的异组合来源保留。不得借用其他建库者的文件填缺。每个来源顺序先补审批和评论两个公共功能，再按字典序补其他缺项，不读取双功能结果。
