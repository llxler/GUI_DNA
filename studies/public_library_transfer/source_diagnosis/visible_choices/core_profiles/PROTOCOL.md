# 先检验共通需求，再让模型选择自建库配置

两款模型在关闭额外推理后均交付八份可编译 Self 方案。Qwen 的控制项 persist 关闭时，已存两条后添加第三条的公开检查会失败；它在多份方案中仍设为 false。此次在两款模型原本的可枚举布尔接口里处理同一问题，两份库、构建者、全部八个目标及可见输出设置照旧。只用公开需求交集，包括修剪并追加不同的待办项、忽略空白、持久化并从公共存储恢复、初始化时隐藏空列表。检查只调用 shell 公开的 init/reduce/select，并读标准 localStorage。每个布尔组合都记录各项结果，不用官方目标通过数筛配置。

八题共用一份合法配置菜单，按与建库者首例的汉明距离、再按布尔序确定固定次序。原模型只根据该题公开需求选一项序号，同时记录首个合格配置固定复用、原首例固定复用和对上一轮模型合法选择作最小改动后的配置。只有模型实际返回的序号记入 Self 主分；确定性投影只作诊断。若没有合格配置，保留该阶段不可部署及之前有效协议的原分。其余三个方法沿用上一轮相同解码、相同八题已封存的候选。单独标注自建库增加的公共配置检验与规划调用。两个模型全收录，即使持平或降低；此为本轮 TodoMVC 最终部署实验。增量至多 0.16 美元，13:55 UTC 截止。
