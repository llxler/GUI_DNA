# 公开需求建库的 TodoMVC 与 WebApp1K-Duo 迁移协议

2026-11-23，在本轮生成前登记。只运行一次，先封存全部库和待测提示，再开放评分。研究对象是两个协议各自原有的全部目标。每次请求使用独立目录、全新订阅会话、相同的 GPT-6.2-astra 和 medium 推理设置，禁用工具，单次作答，不修复或用测评结果选择样本。每个目标生成一份无库代码，每套库再生成一份模式内方案。两个库分别与同一份无库代码配对，并回放建库者自行指定的首例。分别报告原始通过任务数，不累加两个库的共享对照。暂不对原服务商、规划模型或多次采样的整个历史矩阵推算成绩。

- **TodoMVC**。两次建库只见公开规范及历史实验的固定页面接口。建库者设计一至六个布尔选项，编写可配置状态实现并给出首例。无库与规划仅见当前需求及相同固定接口，规划另见菜单。沿用同一页面外壳和八组特征；每项目标要求其适用的官方 Playwright 测试全部通过。评分可以在首个反例后停止；不报告部分断言分。禁用项不受原协议负向断言约束。
- **WebApp1K-Duo**。选用原清单的全部十个二元组合，分为两个类别，各五个。每套库按类别独立提交一次生成，输入原清单十五份公开单功能测试（两个类别分别七份、八份），不提供二元组合清单或组合测试。建库者自定组件名、功能实现、说明和固定首例；组件使用 React 的默认导出约定。有限接口允许从本类别库中挂载两个具名组件，各槽可留空，同项去重；宿主转发 props，按槽位次序挂载。每个当前目标的直接生成和规划都按原基准看到完整公开二元 Jest 测试。通过需该文件四个断言全过。两个类别独立呈现，可按同一次建库重复合计。测试即题面，此协议没有隐藏断言。
- **共同边界**。编译器只注入经封闭 JSON Schema 约束的布尔值或枚举值，不接收新逻辑。校验错误计为该预登记目标失败。底层测评基础设施错误可离线重放原产物。建库、规划和直接生成分别保留提示、原始返回、会话、用量、文件哈希和状态。未计入 API 账单的订阅调用另报，订阅价格不折算成 API 成本。来源为项目历史阶段的只读公开输入与固定测试运行器。固定首例不使用目标提示。
