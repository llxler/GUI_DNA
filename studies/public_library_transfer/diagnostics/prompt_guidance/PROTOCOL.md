# 两个历史 3/20 项目的建库提示配对

在本批及十项目迁移研究的新 table、svg-chart 项目官方成绩形成前登记。项目和范围由此前两个同为 3/20 的记录确定。对每项各做两次独立订阅建库，以简短任务指令代替强调起始 DOM、状态转换、需求冲突的建库指导，保留同一模型、严格输出结构、公开输入、公共编译和准入、修复次数与两套独立库。测量两组各自首例在同二十个当前文件上的表现。首例由各建库者给出，不根据成绩挑选。两组都使用同一套确定性装配机制，本对照只检验额外建库指导，不能把历史 GPT-5 与本日 GPT-6.2 Astra 的差异解释为纯提示效果。每对重复是独立建库而非共享采样随机数。
