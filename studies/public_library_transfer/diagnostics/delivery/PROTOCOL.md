# 从零生成的 JSON 交付敏感性

在前四项目生成且 form 归档后登记。本研究只重新解释同一 Qwen 原始响应。原严格封装已有多例源代码字符串含真实换行，亦有 JSON 之后附说明的情况。对十个项目、所有 200 个目标统一执行。严格通过的原文件字节始终原样复用。其余响应只允许单个 JSON 代码围栏、JSON 字符串内真实控制字符和完整 JSON 对象后的普通说明文字。拒绝重复键、额外 JSON/代码块、文件写入冲突和截断。没有代码生成、语义修复或隐藏测试反馈。对新恢复的页面重跑相同当前官方文件。恢复率、原本/现在的通过数和与每个建库重复在相同目标的差异分别报告。此阶段属于事后协议敏感性，不替换预登记基线。
