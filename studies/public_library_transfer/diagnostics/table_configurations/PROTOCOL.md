# 表格项目两套公开需求建库的完整配置空间

本阶段在两套 Codex 建库的逐题结果与首例结果出现后提出，属于事后机制核验。输入固定为 11 月 23 日统一迁移研究中 `table/codex-1` 与 `table/codex-2` 的正式包及其起始工程，官方目标为表格项目的任务 1–20。两库分别只含一个二值枚举和三个布尔字段。登记全部 2 + 8 个合法配置，各生成一次页面，对每份页面分别运行二十个当前官方文件。全部 200 个位置须先封存才能开始回放。每个配置与目标只计一次；项目、合同、目标与完整页面字节均相同可引用已有原始报告。没有模型调用，也没有额外训练或隐藏反馈。

每个库单列首次公开示例、所有并列最高分的单一固定配置、均匀抽取一个合法配置时的精确期望，以及允许每道题事后选择任意设置时的可达任务集合。固定页的最高分及逐题可达上界均使用官方结果事后计算。逐库取已封存 Qwen 和 Mistral 实际部署通过的任务集合，检查是否为任一固定页通过集的子集；同时核对实际输出的配置、页面字节和原始浏览器报告。后续对受测项目、模型或配置的不完整观测不替换本次定义。
