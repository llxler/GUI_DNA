# 布尔定义的等价写法

开放权重建库初期的三个格式拒绝均含显式布尔值表。在知道这些公开错误后、取得本批浏览器成绩前，为全部十二个预登记项目与建库者组合登记零付费诊断。仅当类型为 boolean 且列表恰含两个不同字符串 true 与 false 时，将该列表规范为原接口要求的空列表。控件名、默认/首例、实现字节、枚举和值类型一律保留。按原响应时间顺序选首个能经此规则通过原公共接口、默认页与首例的包；不根据成绩选包。第一轮未成为候选的其他原因继续保留。原开放权重实验及失败数均不回填。沿用开放权重协议的所有目标，重新运行冻结本地 Qwen 的真实闭集规划，复用原 Qwen 同题直接输出及各库固定首例。只运行当前官方文件。诊断不消耗新的 API 费用。
