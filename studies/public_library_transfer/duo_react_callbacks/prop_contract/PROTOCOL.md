# Duo 中视图入参与跨函数状态的复查

纳入上一轮 Qwen3.5 两套各十五个组件、全部十个直接页面。接口检查记录到模型交付了 View({vm})，而调用者给的是 View(props, vm)。先分析模型实际声明；仅对第一参数显式解构 vm 的视图，把现有状态放入该同名字段。模型源码、路由、合法导入与存储保持原状。若公开单功能仍失败，各候选允许一次由原模型重写完整 React 模块，提示含原源码、公开单功能语义、精确公开错误和真实调用约定。每项改动须减少失败的公开用例且保留原先通过的用例。对已有公开成功的候选不产生重写费用。

自建库仅见一个功能。从零组同时见两个功能并享有同样的接线与修复。每域仍需至少一项单功能的两条检查全过；保留选项、首库、独立第二库、固定页、直接生成、确定性名称组装及全部十对成绩。公开单功能与组合测试有重复，此实验度量公开需求的工程复用。两份库和所有对照封存后，才启动官方组合测试；两域都建成、共同分母完整时才能用此协议更新整行。新增上限 0.75 美元，04:42 UTC 截止。
