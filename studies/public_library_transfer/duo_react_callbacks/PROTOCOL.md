# 两阶段 React 回调与视图

固定 Qwen3.5-9B（公开单功能失败较多）与 DeepSeek V4 Flash（第二模型复验）。每种模型独立生成两套十五功能组件。每个功能先写 useBehavior(props)，再由同一模型读取该钩子的代码写 View(props,vm)。两者都由模型实现；研究者只绑定 React 标准钩子、可用路由钩子、组件入口和 props。公开契约是按执行顺序展开的单功能要求。先验收源码、再运行公开的两项单功能检查；最多修一次有问题的函数。选修对象依据公开错误：找不到控件或重名改视图，其他状态/网络错误改行为。能加载的库保留所有能解析的组件，不按官方组合结果选模块。每域至少一个功能的两项公开检查全过才入组。部署按公开名称选择两个模块，另报固定前两项及按名称组装。原研究已披露双功能断言在公开单功能材料中重现，本阶段不当作未见功能泛化。

在完全相同的两阶段接口下，另让同模型针对每个目标从头写一份完整钩子与视图，可见两个构成功能、生命周期与同样的公开修复，得到本阶段自己的 Direct，不沿用旧成绩冒充。首库 A 为主、B 只作复验；先封存所有源码、选择和固定页，随后执行十个官方组合测试。这个新协议的 Self 与自己的 Direct 成对报告。若两个域均准入且同题所有方法都有观测，在主表可使用同协议的新 Direct/Self，与已登记的真实 GPT-5 迁移库在相同题目上并列并注明实验界面与控制组变更；未准入者保持历次实际观测并披露本次失败。上限 1.25 美元，截至 04:42 UTC。
