# 开放权重模型独立建库

本阶段在订阅建库的部分成绩已知后提出，检验不同建库模型能否迁移同一份已冻结方法。在新调用前注册所有条件。GPT-OSS-120B 在十个项目各建一套库；Mistral Small 3.2 在两个此前为 3/20 的 table、svg-chart 各建一套。实际发起独立 API 生成，身份与之前十项目订阅组分开。两个重点项目跑全 20 题，其余八项均跑预定里程碑 4、8、12、16、20。每项目的部署模型与共用直接响应在生成前指定：draw 使用 GPT-OSS，其余使用 Mistral。复用当日本轮对应模型在同输入上直接生成的真实响应。部署只返回合法接口配置；建库使用十项目相同公开材料、严格输出信封和公共编译器，每套仅允许一次公共格式/加载修复，固定第一次示例。每个建库者一份最多 1.50 美元的账本，含其产生的库及后续配置；此前的无库共用请求只在原账本计一次。硬截止 09:24 UTC。同一模型若收到明确的 403，不再提交该模型的建库请求。未取得响应和有响应但未过接口验收分别记录，各项目封存后仅测试该当前文件。
