# 问卷项目的 Self 建库复测

在看到新表格或问卷的评分前，选定 Web-Bench 问卷的全部 20 个当前任务。建库与组装模型固定为 Qwen3.5-9B 和 GPT-OSS-120B，各自独立封存一套库。问卷的公开起始页面含 JavaScript 入口和表单，与表格同样可用通用模块建库器运行。旧协议中，两模型在此项目均有已交付的从零页。

复用表格阶段登记的模块设计、逐文件实现、入口整合、公共行为检查和一次公开修复预算。每套库分别测试逐题选择和固定首例。模型只见公开需求、起始工程、自己生成的内容与公开检查。每题仍只运行官方当前文件。

按模型和目标编号连接旧版从零生成、旧版 Self、新版 Self、固定新版首例。分母限定四者均有已知结果的目标，同时发布 20 题的逐臂覆盖、结果和未决原因。已返回但无效的产物记失败，服务或传输未交付记缺失。封存生成后再运行官方评分。每个模型单独限额 1.50 美元，最晚 05:18 UTC 停止新调用。此次改变同时增加生成次数和输出预算，不能据此分离某一项提示改动的贡献。
