# 已生成补丁的部署位置诊断

此阶段复用「首份设计归一化」中 GPT-OSS-120B 已冻结的表格初始源码、原始公开报错、修补请求及回答、二十份原始配置和首例。该阶段的另一个模型没有收到可用设计或补丁，不具备部署位置诊断的输入。该诊断不调用任何模型。分析的是已有补丁写入哪个文件，不能作为新的端到端建库成绩。

解析 Chromium 原始公开报错中带引号的缺失导出模块路径。只有当模块的末尾文件名在已冻结的源码集合中唯一，且与补丁源码首行注释自报的完整本地路径相同，才将整份原始补丁应用于该文件。其余文件逐字复用修补前初始版本，包括原始入口。任一条件不符时记为不适用。正式数据与历史修补不覆盖。

对新的首例重复公开加载和原模型自定的交互试验。若页面加载报错，交互探针记录为未执行。为衡量部署本身，仍材料化全部二十个旧配置及同任务固定首例，并在封存后交给未修改的当前任务测试；明确记录公开加载状态。评分前登记匹配规则、冻结输入、评分代码。发布每个官方结果、与原部署的逐题配对、源文件/收据哈希和新增 API 开销零美元。
