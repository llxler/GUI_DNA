# SVG 图表库中已有组件的入口接线

见到旧项目公开起始工程和本轮已封存库源码后登记。研究者已知此前官方分数偏低与 GPT-5 的几何对照。本跟进同时使用 Qwen3-Coder 和 DeepSeek Flash 两个当时完成的 Self 图表包。不查看官方测试、诊断堆栈、参考渲染器，亦不根据得分选择变体。本阶段没有新模型采样，不能称为纯 Self。现有两款模型及其所有 20 题分别公布。先记录公开运行和修复，冻结所有候选，之后作官方评分。

图表公开工程使用 configs、按类型创建图表对象及预留的 root，公开要求命名了实例的 svg、draw 与承载 DOM。两份自产库及其自定义脚本原样使用。研究者提供同一条领域接线规则：在起始入口的 chart = new Class(config) 语句后，将该对象真实生成的 svg 追加至 root，然后调用其已有 draw（如果提供）。没有插入任何绘制元素、坐标公式、类型映射或样本 ID；不新增类。仅当旧入口包含相应结构、且没有既有挂载或 draw 调用时才接线。比较原首例、接线首例、公开错误修复后的首例、接线并修复后按既有规则逐题选配置，以及两个原固定设置（全开和全关）。

图表首次在公共样本上启动后可获得一次仅限作用域的确定性修复。若浏览器报告 ReferenceError: 某名 is not defined，且库的自编模块恰在一个条件块里唯一声明了同名 const，允许把该块内以该声明为中心的连续简单 const 表达式提到这个条件紧前。依赖须是父作用域已声明的标识、同组先前变量或受限的数学和数组表达式，不改变任意表达式源码。本研究的修复器只放行标识、属性读取、基本算术、Math.min/max、数组 flatMap 与只读箭头表达式。源码不合格则原样保留。对第一份固定示例的原页、接线和修复页分别在两个公开浏览器上下文读取错误及实际挂入的 SVG/图形数；记录每次观察。库不含渲染实现时保留空结果。两库的全部页及预生成方案在任何本阶段官方文件启动前封存。本阶段的公共图形计数用于定位实现或接线缺失，不是官方结论。
