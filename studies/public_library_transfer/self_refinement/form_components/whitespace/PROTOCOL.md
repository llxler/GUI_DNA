# 问卷的 JSON 空白对称敏感性

问卷原批次已封存。收到的部分源码文件映射以正常结束标记返回完整 JavaScript，外层两个闭合括号之间却使用字面量反斜杠加 n。本阶段在读取本批官方成绩前预登记一种对称解包。首次解析失败时，逐字符扫描整个回复，只将 JSON 引号外的反斜杠加 n、r、t 改为相应合法空白，引号内包括所有源程序字符逐字保留。不补括号、代码或文件。所有 31 份无库初稿/修复回复、40 份逐题方案和 2 份固定方案使用同一变换。模型写的原始 JS 模块本就使用纯文本协议。

无库初稿若经解包恢复，在原起始页重放同一公开探针；按原顺序决定是否采用已有第二次回复。初稿通过公开探针时即选初稿，其余采用最终有合法页面的机会。不新增模型调用；真实截断的字符串按原口径保留。全量候选、变换代码、原回执、选择和任务文件在运行新增官方评分之前封存。原页面和原始分数保持可核对；相同任务和字节的页面沿用原官方记录，变化页面另行执行相同任务文件。发布两套库、从零初稿与有公开反馈的从零、固定全量页在二十项上的成对结果。
