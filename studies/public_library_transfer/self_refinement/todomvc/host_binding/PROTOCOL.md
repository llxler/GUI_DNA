# 宿主保留名的确定性绑定

在原两份 TodoMVC 源码和公开组合报错中发现，宿主和模型都在同一作用域声明 DNA_CONFIG。本阶段仅针对初稿 A、B 两份，不读取一次模型修复后的源码及官方评分来调整规则。本阶段无 API 请求。固定初稿接口、每个已选配置、固定首例、从零真实对照及原官方评分器。

条件同时满足才做一次变换：文件开头为一个独立完整的 const DNA_CONFIG 声明，初始化值是只含显式布尔字面量的对象，字段为无重复的无引号 JavaScript 标识符，与原真实控件集合完全一致，而且没有展开、调用、计算属性或其他表达式。仅移除此声明（保留其他字节），由原装配器为每个页面提供它本来就要注入的只读配置。未匹配的源码不修改、照实公开检查。保存原始、被删除声明、保留部分和完整候选的 SHA-256。每份库保留组合语法及公共接口检查报告；若有效则逐一重放初稿对应的八个已选配置和固定首例。两份库共 32 个位置封存后才读取官方成绩，匹配的重用来自同一目标与源码。结果与原始两次及独立的一次模型修复分开。
