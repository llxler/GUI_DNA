# Gemma 从公开 TodoMVC 需求构建可配置控制器

两次独立调用 Gemma 3 12B Instruct，从完整公共需求写出控制器的状态、事件、视图与布尔控制键。建库输入没有人工实现、官方测试、历史候选或历史成绩。分别保留模型写出的默认程序和每项新需求的真实模型配置。八题共有一组同模型、同提供商的直接生成。初稿与一次公开诊断修复后的方案均单列。[预登记协议](PROTOCOL.md)

对每个键只翻转它的值，其他键保持原默认。两端分别执行两次同一组公开检查；至少一个检查稳定返回不同且一端通过、一端失败的实际值，才向逐题模型提供该键和两端观察。两份控制器没有共用配置接口。若只有可交付的实现而没有有效选择，只报告默认页，严格组装流程计失败。建库者为完整任务族准备，直接代码依据本题需求，两臂均获得一次公开修复机会。

每个官方目标独立运行当前 TodoMVC 断言集合。传输缺失在配对分母中排除，已收到但不能交付的代码或配置按失败计入。收据、原始费用和候选源码的哈希按模型回复区分。已结算费用逐请求按微美元进位。新账本位于本机 artifacts/todomvc-gemma-verified-20261124。
