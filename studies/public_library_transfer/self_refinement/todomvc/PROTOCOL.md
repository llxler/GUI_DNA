# Qwen3.5-9B 自建单入口 TodoMVC 控制器

独立复测原套件的全部八个目标 todo-01–08。Qwen3.5-9B 在旧协议中从零生成通过 1/8，自建库通过 0/8。本次在查看新评分前冻结两个独立建库种子、一个无库生成种子及原有目标和评分器。TodoMVC 的公开宿主页负责 DOM 和事件，模型只需实现 init、reduce 和 select。本项目为单入口控制器，与多文件 Web-Bench 的结果分开报告。

两个库均只获得原套件建库者所见的完整公开需求及宿主接口。先以提供商原生 JSON Schema 描述 1–6 个语义明确的布尔控件及第一份示例，再在一份普通 JavaScript 中整体实现这些控件与状态。调用 Qwen3.5-9B，温度 0，关闭推理，要求路由支持参数。接口设计最多 4096 输出 token，整体代码最多 12000。两次独立建库种子为 20261124、20261125。整段 Markdown 代码围栏可机械剥除；检查原有控件格式及 JavaScript 语法。只在语法不通过时允许一次公开语法错误修复。原人工库、测试、已有实现和结果不进提示。

每个目标的无库组获得与历史协议完全相同的本题公开材料，使用相同模型、关闭推理，直接交付整段 JavaScript。无库种子为 20261124。每套库在每个目标上各请求一次符合其真实原生 JSON 模式的配置，并重放建库者事前写定的固定首例。无库和配置输出均上限 8192 token。每个任务位置使用首次响应，不以重新生成填补失败。先封存全体候选和配置，才调用原 TodoMVC 官方功能子集评分器，复用相同候选必须同时满足目标和候选源码哈希相同。传输缺失记空，收到的无效代码或模式计失败。每库分别与真实共用无库对照、自己的首例以及原协议结果配对。
