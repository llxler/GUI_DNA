# 本地模型按 TodoMVC 的公开宿主接口独立建库

从人工库借用共享状态、分事件处理、统一持久化和视图派生的结构。研究者预先从公开宿主登记事件签名、五种开关和通用分发器。模型编写每个操作、读写存储及视图的 JavaScript，并在逐题阶段自己选取五个开关。这是有领域脚手架的 Self。人工库、测试文件、既有候选和分数均不进入新提示。

两份独立 Qwen2.5-0.5B-Instruct 库，种子 2711、4513。两个公开事件合约复用同一状态。同一模型分别编写 init、persist、select 与各单事件处理器，输入真实公开约定及相关规范段落。批次内按函数单列响应，每函数最多 384 token，温度 0.45、top-p 0.9。用 JavaScript 解析器提取返回的首个符合请求名字的完整顶层函数，签名不合或截断时允许一次仅含公开格式错误的重写。不为失败函数补写业务实现。必要的初始化、持久化、视图和新增事件任一缺失即记录建库失败；其他未交付的事件在接口里登记缺失，分发器保留原状态。固定对照启用模型实际交付的所有开关；另跑禁用所有可选事件。逐题以相同权重贪心约束解码配置，每个目标一次。这个对照测领域分解后的整套工作流；研究者提供了模块边界并承担了对应工程准备工作。

从零组用同一宿主、同一权重和各目标公开需求直接生成整个 JavaScript 控制器，每题首次贪心输出，最多 2048 token。允许完整代码围栏。与库一样从完整的顶层语句提取原代码，失败时不补写。所有 8 个任务、所有尝试和所有目标固定页同时封存，再在相同宿主页上运行原 Playwright 当前功能子集。目标及源文件均相同可共享收据。两个库分别和这八份从零候选比较，建库失败计零，缺测保留。记录准备与部署的输入、输出 token、函数交付与模型选择。实验只使用本地权重。
