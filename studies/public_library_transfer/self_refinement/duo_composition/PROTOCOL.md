# Duo 单功能模块复用与确定性组合

这是对 2026-11-24 原六模型建库答复的离线方法实验。事先知道原总体成绩和格式失败，先审查输出的表示形式，冻结本协议、抽取程序、配置和所有候选，再运行原版组合 Jest。此次生成成本为零，历史代码的生成成本按原账本记录。正式结论只涵盖登记的两个域、十五个单功能和十个组合。没有登记人工 Duo 实现。

- 全部纳入原六模型、十二份原始答复。抽取时只允许看该答复与公开单功能材料。接受完整 JSON 的组件记录、截断回复中已经闭合的 JSON 组件对象、静态 JavaScript 组件数组的字面量、以组件文件路径标记的完整代码块。只接受合法 ID、可解析的 React 默认导出、且所有依赖限于 react 与 react-router-dom 的模块。禁止调用任何生成器、执行代码获取字符串或修补业务逻辑。先出现的同 ID 模块优先；无有效候选的任务计失败。登记原始文件、逐组件源码和各任务配置哈希。
- 为每个域单独匹配。以公开单功能标识符、公开单功能中出现的 API 路径、原答的组件名称及源代码为输入。精确匹配标识符优先，其次匹配公开 API 路径，再按标识符词片段、组件描述相似度排序。目标之间的一对一分配取全域匹配分数之和最大者；并列按公开名称排序后依次优先原组件顺序。没有共同证据时保留缺位。整个领域映射冻结后才用公开 Duo 模块名中明示的两个单功能标识装配，使用原有组件装配器传递 props，不改模块字节。该方式使用基准提供的显式分解。
- 对照组固定复用每个域原答中最先出现的两个可执行组件，只有一个时单独挂载。另从冻结汇总取同模型逐题 Direct 与原模型规划 Self 结果。每项均运行全部四个原官方用例。合法响应无模块或未能装配的目标计失败，实测传输缺失保持缺失。所有报告均逐模型列出，使用同一共同目标分母。
- 十个组合的四十个官方用例与这些公开单功能文件的用例重合。故此实验只检验已公开功能的恢复与组合；没有独立的隐藏功能泛化或新模型规划证据。每份原模型答复只生成过一次，协议在历史结果公开后确定。
