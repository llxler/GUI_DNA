# React 默认导出声明的从零敏感性对照

对称解封完六十个 Direct 后发现 Mistral 的代码反复将函数写成非法的独立 `default function Name(...)`。为量化该格式问题，在看任何修正候选的成绩前冻结以下限定规则，对所有六模型的十个源文件一律执行。若代码在行首恰好一次出现 `default function Name(` 且有单独的 `export default Name;`，去掉前一个 default 关键字。若只有错误声明且文件完全没有其它默认导出，则只在该行增加 export。无其他变换，需通过静态模块、默认导出及依赖检查。没有完整文件时或匹配失败时保留原处理；论文本次仅以它作为给从零方案额外帮助的敏感性对照。这一规则基于已观察到的错误模式，诊断属性单列。先封存全部源文件，受影响者另存并评分，原始成绩原样保存。
