# TodoMVC 与 WebApp1K-Duo 的自建库复测

本轮独立账本上限 $2.50，使用与 Web-Bench 相同的截止时间。名册固定为 TodoMVC 的 Gemma、Qwen3.5、Mistral、Qwen3-Coder，Duo 的 GPT-OSS、Flash、Gemma、Mistral。每格两份从零准备的库，A 为主格，B 为独立复验，保留失败或较低的成绩。同模型部署，原批直接组与人工组按目标复用。固定配置和逐题方案均封存后才评分。

TodoMVC 生成单一状态控制器，要求把事件分支放在独立作用域内、避免 DOM 渲染代码，用生成者自定的布尔键控制实际行为。最多一次公开事件及状态差异反馈，沿用已有的公开动作检查和无回退措施的修复接受规则，至少有一个公开行为通过、一个配置键能在重复切换中稳定改变公开行为，才准入。默认配置为固定对照。目标生成者只接触原公开需求及经过公开验证的设置。结构错误或规划失败照实计。

Duo 按公开的十五种单独功能逐个写 React 组件，每份都必须可解析；可根据该功能公开的两项 Jest 断言修复一次。接受改稿须严格增加公开单功能通过的断言数。出现公开 runner 崩溃时沿用原套件已登记的复核程序，否则保留未决状态。一个领域的所有模块均可编译，且至少一个功能通过两项公开断言，才能以该领域的五项成对任务进入比较。规划只选两个已冻结组件，固定对照使用名称顺序最前的两个。组件验证可能包含成对任务复用的单功能断言，公开披露。这项研究衡量公开功能组合，不作为未知操作泛化证据。新库可用域扩大时列出新评测范围，旧域相同目标另记。每边只按实际已接收规划且对照明确的共同题比较。建库与使用的调用、未决预留分列。两种研究的收支上限共 $10，评分程序和官方判定不变。
