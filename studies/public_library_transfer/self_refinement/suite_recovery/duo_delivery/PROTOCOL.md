# Duo 唯一 JSON 代码块的离线复验

Mistral 在已完成的双库实验中共给出二十份回复，原接收器均拒绝，抽查发现正文后附有 JSON 数组。此次诊断按全部四个登记模型、十个组合、两个重复统一执行。先登记、封存所有候选，再做新的官方判定。保持原协议和主表成绩，另报告复验。逐题规划和从零生成沿用其真实旧回复，固定组件对和已准入领域不变。

先接受原协议已接收的源码或方案。原解析失败且已交付回复时，仅允许提取全文唯一一个显式标记为 JSON 的围栏。内容必须完整解析、符合该方法原交付合同。多个围栏、缺少围栏、模糊文本、代码补写、组件名猜测均不处理。不根据官方分数选择候选。对无库回复同样按其原 JSON 源码信封验证。每份试验在已准入的共同领域上比较实际从零、选配和固定对。单独记录哪些目标仅因接收方式恢复。这个复验衡量回复交付，与新建行为实现分别呈现。额外 API 费用为零。
