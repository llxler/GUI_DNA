# 根据公开浏览器异常修复已有 SVG 源码

原始 Qwen3-Coder 两份独立库均报无法找到父类。向所有部署开放唯一导出的父类链接后，在两份固定页都观察到 DOMTokenList 拒绝含空格的 token，原宿主捕获后重新发出的 error 事件未出现在原 Playwright pageerror 回调。登记时仍未运行本批 SVG 的官方测试。本阶段是同一批库的一轮追加修复，不作为额外两次独立重建。程序登记后，本批各阶段的全部新候选均封存再读官方结果。

在每个来源完整的候选上，以同样的公共资源加载网页，捕获窗口 error（含显式派发）、未处理异常和 pageerror，观察六类公共输入的真实图元与挂载。A/B 各取最终全开页，从零取二十个目标的最终收到的页面。观察到错误或当前预期的图形未出现才向同一 Qwen3-Coder 模型请求一次。模型收到真实文件和观察，在自己可编辑的文件中给出精确匹配的源码替换；可以显式一次替换一文件内的相同片段。不得编辑公开数据。库只能改已交付的渲染源码，从零可以改整页。每个候选最多一次模型修复、相同输出预算和提供商。仅当已有能画出图元和已有能挂载的类型都未减少，并且无新增错误数时接受有改善的补丁：能绘制种类或能挂载种类增加，或去重后的公开错误数下降。诊断不同但数量相同不触发接受。缺失修复响应保留原先已交付的页面，未交付的初始样例单列。

重新用同一模型逐题选择两份库的六个配置，输入为当前公开前缀与修复后实测；全开为固定页。原有计划经修复版本也重放，区分实现变化与新规划。无库首稿、反馈后旧页和此轮处理后的直接代码保留谱系。报告原始、仅链接、定点修复各阶段，两份库共用同一组从零。去除无需图形的资产题单列。研究者提供六种公开图形类型到类的接线、模型可以修改的源码界面及观察工具；未提供算法、样式或补丁答案。
