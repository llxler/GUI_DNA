# 公开单功能运行的进程异常

2026-11-24，在本阶段第一份组合成绩之前，Qwen 为未传对应 props 的候选调用了无有效地址的 fetch。Node 因未捕获拒绝退出，Jest 来不及发布 JSON，原评分器报找不到报告。保留原响应、候选和标准错误。对具有可定位 JavaScript 错误终止并缺少报告的目标，再次在相同 npm、Jest、测试、候选与依赖上以 Node 的 --unhandled-rejections=warn 记录断言诊断。二次输出必须确有未通过的同一官方断言，且进程非零，才把原始结果记为失败。重放不能将原本崩溃的候选改判为通过；若无法复核，停止该分支并披露。适用于全部单功能与组合，包括 Direct，发生异常的范围在最终结果另列。

此修订仅涉及已生成程序的失败证据。它不更改提示、请求、分数通过条件或产生新的采样。恢复时从已落盘的计费回执继续，只向尚未尝试的计划位置调用模型。组合反馈继续隔离。
