# Qwen 的精简公开行为契约

首批两个模型已封存；Qwen3.5-9B 原两次组件检查仅 0/15、1/15。同批常见错误包括画面附加样式的 JSX 语法、嵌套路由、重复控件标签、未导入钩子、缺少实际要求的测试 ID。此复验在新生成前单独登记，适用于同一已调试领域。预定两次独立库、每库全部十五个公开组件及每次十个目标，另有同设置新 Direct 十题，之后停止本优化系列。

只更改模型收到的公开规格表达以及代码简洁要求。将公开单功能或公开组合经同一 AST 提取器展开为逐例、按顺序的公共请求配置、渲染 props、用户事件及结果断言；同样保留函数中声明的数据。原文件 SHA 留存。结构来自原公开测试，人工不提供具体业务名、路由、选择器、文本、答案代码或组合规划。React 采用显式命名空间钩子，要求只交付可访问必要控件和消息、不要内嵌路由、演示数据、样式或附加控件。基准包装层提供 MemoryRouter。保留同一模型、温度、输出上限、解析和两个公开断言检查、最多一次公开错误修复。直接源码与带库源码收到完全相同的精简指导；Direct 也按其两个已知单功能文件检查和修复，另保留首轮。逐题配置同样使用新表示给出的公开组合契约和原冻结组件名称。原阶段的十个组合同样本，均同时报告模型规划、显式名称匹配和域内固定头两项。创建新种子和账本，原账本不动。定稿前保留原、复验两次结果与所有未通过的目标。对公开特征已知且组合断言重合的局限不变。
