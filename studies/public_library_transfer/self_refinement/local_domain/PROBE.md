# 计算器公开交互与固定组件诊断

主协议冻结后、取得任何新评分或读取建库输出前另行登记。该诊断不参与建库、修复或选择。对每个独立库，以相同起始页装载其已生成的按键和通过语法检查的通用面板，省略二值行为的设置逻辑，将这一份静态页面固定用于全部 20 个当前任务。这能在二值方案未交付或选项设置影响组件时，单独观察按键组件的可用性。

对以上固定组件页，以及主协议中每份实际封存的 A/B 端点，在全新浏览器页点击起始页数字 4，再依次对每个新按键单独打开一页，点击该键。仅记录显示框的前后值、控制台错误、可见按钮及顺序、按钮计算样式、元素 id/按键文本。所检查的标签来自建库输出；该诊断没有逐题断言。两端存在相同与不同的可见行为均记录。两种配置的源代码不同不能代替有可测行为差异。诊断页面另计全部原版当前任务，仅对独立固定组件页报告通过分母。逐题成绩不能用于更改首例或挑选配置。
