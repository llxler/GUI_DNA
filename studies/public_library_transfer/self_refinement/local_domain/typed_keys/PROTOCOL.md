# 计算器领域语法与模型选取

首批小模型给出的运算体在公开解析阶段含未定义符号，两份库均未成功表达二值说明。另立受限语法实验，保留首批。冻结本协议时尚未读取任何新官方评分。两个阶段使用同一批本地模型从零回答。

研究者提供领域语法和绑定器。它从公开英文句子中找带有文本、符号或枚举名称的新按键，从明确的顺序交换句子登记两个端点。名字与标准 JavaScript Math 属性明确匹配的按键、标签本身就是合法算术式的按键直接链接。内存、其他未能链接的按键交由模型在有限运算语法中选取。语法支持标准一元 Math 调用、数学常量、基本算术、共享存储变量读写。登记绑定器的确定性单独对照：仅装入能直接链接的数学按键，使用原始顺序，不含任何模型产出的运算和补充面板。不能把该对照也实现的收益归给模型。

两次独立生成使用 Qwen2.5-0.5B-Instruct，新固定种子 9203 和 9923。每个未明确匹配的按键从以上语法按模型概率采样一次。每库再分别生成计算器外观、内存和历史面板；仅接受有效 JavaScript 语法，其他记录为空。公开起始页、需求、显式领域规则为所有建库输入。完全相同的按键对用原始顺序以及互换顺序生成两份页面。固定两端和逐题 Qwen 贪婪选择均比较原版的同一当前任务测试。对 20 份新原始 HTML 从零响应除原始完整文档口径外，再以宽松的浏览器口径解析，保留有 html 和 body 起始标记但缺少结束标记的页面。这一较宽松的 Direct 是本受限语法实验的主比较。所有程序在官方评分前先封存。
