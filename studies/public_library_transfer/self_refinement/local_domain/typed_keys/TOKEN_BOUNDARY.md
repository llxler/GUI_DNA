# 语法候选的联合分词复核

本地模型为全部按键选择程序的条件把字符串 `return ` 和表达式分别分词。Qwen 的空格加 Math 存在合并 token，空格加数字则保持独立。公开分词器即可复现这一不对称。本次保留原响应和设置，复用相同提示、权重、全部候选程序、CPU 精度和随机种子，把提示与候选结尾放在一起分词，逐 token 约束采样。先对所有 26 个按键比较两种分词产生的程序，再记录它们分别与标准 Math 或字面式直接链接吻合的数量。这一步只检查九项有确定链接的公开定义。对两个库均保留全部选择。若追加浏览器回放，使用原封的两个界面面板、原有双端点和全部 20 个模型选择；从零和纯绑定器均共用相同前期收据。
