# 从已实现的行为中提取可执行选项

在读取模块链接阶段任何官方成绩之前登记。输入限定为刚刚通过公开加载的 Qwen3.5-9B 表格 A、B 两份原始链接包与公开需求；两份都纳入。问卷、人工库、冻结 GPT-5 库与官方断言均不进入建库或选项设计。选项提取者与部署者仍为 Qwen3.5-9B。两个原库及其固定示例是可核对的相同基线。没有新行为模型或人工编写的项目分支。

1. 模型独立提出 1–3 个有语义的二元选择：给出说明、原行为、替代行为、一个具体本地 JS 文件、该文件中唯一的原文片段和替代片段。原行为保留源代码原字节。替代行为只替换该段文字。两处重叠则按模型给出的顺序保留首个合格者。禁止题号、整页查找表、纯探针标记和任务编号分派。允许一次公开格式/源码定位/行为诊断返修，只修未通过的名额，原已接受项不能替换。
2. 对每个候选验证唯一原文位置、真实改变、非重叠、JS 语法和两种值下的完整首例公开加载。模型还需指定同一条最多三步公开浏览器交互，和一个 CSS 观察对象及其计数、可见性、文本或值。两种选择分别在两个全新页面上重复；均能完成交互、且各自末状态可复现、两个末状态不同才确认选项。记录失败、超时、无可观察差异和无法确认的情况。加入选项后，所有已接受选项组合均需正常加载。没有通过验证的选项就记录不可组装；原示例仍能单独评分。
3. 每个库先冻结选项、原文位置、描述与全部源码，再让同一模型对 20 个公开目标各选择一次。方案为闭集数据，逐题调用不能改变源码。组装器在仍使用原固定配置的冻结实现上按位置从后往前替换；全选原行为时，文件集合必须与原固定示例逐字节相同。两个库及 40 个部署位置封存后，才运行各自官方当前任务文件。设置比较还包括相同条件的已有从零页面。可对至多 8 个组合的固定实现做全目标离线穷举；与真实逐题选择分别呈现，不能作为可部署成绩。若资源不足，优先实际方案与原固定示例。
4. 此验证是已有实现上的再配置，不是独立从零建库。无可用选项的逐题格按真实方法失败计零；服务和预算中断单列，不把它们记为程序失败。一次表格项目独立账本新增上限 0.65 美元，目标和提取调用分项保存。2026-11-24 05:18 UTC 停止新增调用，未知预留保留。此协议完成后不再增加新方法。
