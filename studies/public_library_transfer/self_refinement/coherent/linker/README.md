## 从已有实现提取控件

最后的诊断只使用两份已经能加载的表格包，生成器从真实函数中提取局部替换并提交自己设计的交互探针。表格 A 的一次点击在原实现下选中 0 个单元格，在替代实现下选中 1 个，两种情况各重复两次。这个替代实现通过第 4 项官方任务，但 Qwen 在所有 20 项部署中都选择原行为，因此逐题结果仍是 0/20。该探针检验了点击，模型描述的 Shift 选择仍缺少相应的交互证据。表格 B 的两轮六个提案没有通过公开验证，组装为 0/20；原固定页独立评分为 1/20。两个库所有可达配置均逐项穷举，得到 60 份配置与目标配对，并保留了正式部署时的独立选择。新增提案和配置调用共计 0.006948 美元。[可执行选项协议](executable_options/PROTOCOL.md) · [行为观测、部署与穷举结果](../../../../results/self-executable-options-20261124.json)
