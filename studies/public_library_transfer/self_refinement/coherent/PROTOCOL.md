# 保持配置设计不变，检验共享实现能否完成交互

从公开加载记录已经看到，分开编写模块容易产生不一致的导出、缺失的路径和语法错误。本研究在原生结构化批次的官方反馈产生前，登记该批两项目各两份已封存的初始设计。全部四份均纳入。Qwen3.5-9B 保留自己设计的开关、语义、首例与公开探针，使用相同服务设置和重复种子，从公开材料重新实现。所有 JavaScript 由模型一次写入同一模块；通用适配器仅在需求提到的本地路径上重新导出这些符号，各路径的默认导出由模型在一个映射中给出。页面状态、行为、类、事件、初始化、选择器及 CSS 仍全部由模型实现。CSS 编写者读取实际 JavaScript。首次公开加载或模型自拟检查失败时，可据公开错误改一次完整 JS 文件。先生成并封存两个库和各自 20 份新方案，再运行本项目官方当前文件。

两个重复独立报告。无库对照为同批原生结构化的 Qwen 首轮从零页面，每题只生成一次；另与原 Self、原从零、本库固定首例及相同设计的逐文件实现对照。同项目同模型同题号分别匹配，保留所有无效和传输缺失。重用设计、从零响应及其费用单列，新增调用每项目限 0.75 美元，截止 05:18 UTC。该开发复测检验代码组织与生成预算的组合；首例能通过的目标用于区分实现改善与逐题选择的贡献。
