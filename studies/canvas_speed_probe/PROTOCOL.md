# canvas 的按键加速量干预

此项是看到首轮射击诊断与 GPT-5 库字段名称后的针对性跟进，不能作为盲选行为或官方任务成绩。登记后在 32k 的全部 GPT-5 与 Claude 库上使用同一规则。根据公开 task-16（按 d 加速各物体）和 task-4（管道横移并公开其位置），以键盘事件引起的运动量作为观察值。使用两个文档示例及从第一个示例出发、向第二示例每次替换一个不同顶层字段的全部合法方案，保留相同源文件和缺失项。

每次在全新 Chromium 上下文使用固定时钟与种子 1、2、3，启动游戏后等待 320 毫秒，记下第一根管道的 x 坐标；按住 d（或另一次新页面中的 z），推进 96 毫秒并重读。两键的起始坐标须一致，原管道仍可观察，两次横移均为正常向左或静止的有限值。加速量为 d 与 z 导致的向左位移之差。参考在三个种子均须出现正的加速量，空白页均须缺失，才能对库作出判断。单字段行为见证要求三个种子都可观察，且相较同库第一个示例，加速量都向同方向改变至少 2 像素。列出完整方向、差值和字段，包含无见证的库。该干预仅描述一个可观察的按键响应，不证明普遍表达能力、选择方案对任务成绩的贡献或跨项目泛化。同一源码的测量可按哈希复用。
