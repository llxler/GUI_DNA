# SVG 渲染后逐项补全

上一轮三个生成模型在新数组和新标签上各有未满足的公开条件；整类重写没有一份产生可保留的改善。沿用全部三款模型和同一批原计划，不按官方成绩选模型。保留旧模型的数据渲染器，注册六个按顺序执行的后置函数候选：画框、轴与标签、网格、图例、线与点、柱形。只为当前两组公开变化仍有失败条件的类别让原模型写一个函数。函数只能接收实例的 SVG 和传入的 config，不添加跨样本行为和持久状态。研究者的新增绑定只在原 draw 返回后传这两个参数，代码来自当前建库模型。逐项确认既有通过条件不丢失、已绘制的图形类型仍在、该类别至少增加一项公开检查；逐个保存接受与拒绝。原本获准的库仍保留，包括所有负例。首库、首个方案以及全部原来的选择照原样回放。完成公开选择后才运行官方当前任务。新增 0.60 美元，04:42 UTC 截止。该协议仍是同一项目上的公开开发实验。
