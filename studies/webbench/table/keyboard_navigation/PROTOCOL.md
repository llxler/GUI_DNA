# 追踪表格按键事件中的选区

本阶段从前次冻结的 Qwen3.5 两份选择状态库出发。单击已有单元格，按向上键，记录事件派发前后的 active、selected、目标单元格的编辑标志、传给选区投影函数的坐标和运行时错误。采样只基于公开的表格需求。两份库分别由同模型重新编写唯一的 navigate 函数，只向该模型提供对应旧函数、公开接口、实际诊断和上下左右、Tab、Shift+Tab 的通用要求。每库一次生成，只以旧公开的连续编辑和方向闭环检查验收：保留旧通过项并新增公开通过项才使用新函数；否则继续使用旧函数。

候选封存后另外保留两段新顺序：单击第二行第三格，向左、向下、向右；单击第三行第二格，正反 Tab 后再向上。参考页与起始页分别校准。所有旧逐题配置、固定页与无库对照不变，每库在全部原二十项当期测试上分别报告。只修改未冻结的新输出中该函数，逐页验证旧哈希。费用上限 $0.20，纳入本轮 $20；不因正式分数调整入选结果。
