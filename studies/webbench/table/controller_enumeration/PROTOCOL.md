# table 六个控制器的完整枚举

2026-11-23，在知晓 table 三流程结果及预指定全开页成绩后登记此离线诊断。它回答相同参考组件库内随机选择方案有多强。原三流程研究保留原始协议和计分。观察到原始结果是发起本研究的原因；六个选择位及其合法取值已在原研究中冻结。

- 取冻结参考包中的六个独立控制器，按冻结枚举顺序给定位编号。每项独立以二分之一概率启用时，64 个子集等概率，包括空集合和全集。每个子集编译一次，对全部 20 个当前官方任务文件各独立执行一次，共 1,280 个目标－配置位置。候选接收同一公开起始工程和同一冻结参考模块，没有新模型请求，不对已有候选重采样。
- 主要量为第 t 个任务有多少子集通过（k_t/64）。报告均匀随机配置通过率的精确有限枚举值 Σ k_t / 1280；在 20 个位置分别独立均匀抽样时，预期通过数为 Σ k_t / 64。此期望不需要假设任务难度相同。冻结的首轮逐任务计划通过数、固定全开页通过数和均匀随机期望分别呈现。空配置页仍包含核心 Table 及库模块，不等同无库起始页。
- 补充描述每个控制器在保持另五位不动的 32 对配置中的逐任务变化（开后通过、开后失败、不变），用于区分控制器是否真正影响行为。配置中的选择在此穷举；每个配置－目标只有一次浏览器结果，外部环境和浏览器自身的随机性不在枚举范围内。
- 使用原研究同版预设（Chromium、Playwright 1.57.0、单 worker、30 秒单例超时、5 秒断言超时、失败即停且不重试）和未改动的当前官方测试文件。原研究结果只在同一目标、相同运行合同且全部页面文件与路径逐项 SHA-256 相等时复用。复用指向原报告哈希，不复用其他任务、近似页面或名称。其余保存新的独立浏览器报告，双 worker 并发上限。
- 以既有产物为只读输入；输入、64 个可执行页面和复用地址在本诊断第一项评分前冻结。结果写入独立目录。中断位置记缺失、另报上下界；全数完成时再给出精确枚举值。官方测试和历史分数保持原样。
