# 由自建表格库的原作者重写菜单事件处理

条件为此前自行划分模块的表格 Self 在结构化声明、完整文件修复、事件轨迹精确替换和已交付编辑数组复验后仍未准入。修复困难包括长文件中的文字无法唯一匹配，以及选格已经能用而两个菜单监听器互相干扰。本阶段从原作者已经交付的完整模块按序取前两份，每次重新生成一套短处理函数。登记在恢复数组的正式结果之前。各模型仍是自己实现和选择的唯一模型。

公共绑定把真实的右键、选菜单项、表外操作与单击单元格分别交给四个处理函数。绑定提供事件、命中单元格、已挂载菜单、共享对象和挂载返回节点的操作。菜单 DOM、按钮、CSS 类、增删行列、关闭菜单、选区效果均由模型编写。保留原作者其余实现并依原设计启用模块；用原库同配置和原固定页检查绑定的贡献。新处理函数只安装在原设计中负责第一项公开需求的模块。若一次公开检查失败，只向相应处理函数提供公开动作及实际结果，各可再修一次；不能恢复就换下一个完整设计重建，最多两份。准入须保留原先通过项、四项公开操作全部成功、浏览器无异常。按顺序取首个准入库。

部署模型对二十项各选择一个模块数，同一决定同时运行新实现和原实现。另评分新旧全开、空宿主。首库成功或穷尽的失败均记录。这个接口由研究者指定，原模型拥有业务代码。费用上限 $1.00，计入同时运行各阶段的完整上限后仍低于总额 $20，付费截止 10:32 UTC。运行 `uv run python -m studies.browser_worker studies.webbench.table.event_hooks.run`。
