# 以模型选区状态驱动可见样式

对同日两种表格弱模型的各两个独立种子，沿用各自已交付的十五个操作。新的研究者通用绑定器把模型声明的 Set 成员关系投影成它声明的 CSS 类；绑定器不会选择单元格、生成菜单、插行或决定业务状态。声明由原模型从公开要求和自己的函数接口生成。用可改变内部状态但不直接改 class 的原操作与该投影共同解决重复维护选区的问题。公开接收按能力计：先在只启用 core+menu 的配置上用真实浏览器验证选中、可见菜单、插入行、无异常；同种子的已存候选依次为契约阶段入选的完整函数集、单元检查各槽优胜、独立通过逻辑选区检查的首个单击/选区组合。此顺序只看公开行为。对键盘、剪贴板、拖选、边缘调整、重排逐项加入，检查确有对应操作且原可用行为不回退；确认后才在模型菜单里提供。报告每个库实际保留下来的能力，不将不可用功能从官方二十题中删去。规划与全开固定、空函数+绑定宿主都测；A 为主，B 为重复。同时保留旧全功能协议结果、构建门槛与费用。API 最多 0.80 美元，截止 04:42 UTC。
