# 自建表格库的事件传播与局部修复

GPT-5 对表格的公开右键轨迹能修复整份库共有的菜单错误。这里检验同一种信息能否帮助自己划分模块的目标模型。登记时结构化接口阶段仍在运行。适用范围限定为 Mistral、Qwen3-Coder 和 GPT-OSS 中穷尽该阶段三份库仍准备失败的模型；已经准入的库继续使用原协议。修复者与建库者必须相同。按原三份设计的生成顺序，从每份设计在公开检查后留下的实现开始，保留原模块边界、宿主和官方测试。若没有任何实现，保留原失败。

在实际页面上右键单元格、点击插行控件、右键表外并单击选格；读取事件前后菜单类名、可见性、选中格和行数。原模型得到自己的代码、公开需求和这一条浏览器轨迹，提交在自己的文件中唯一匹配的精确文本替换。每次最多八处，从解析到语法都核对；允许一次格式纠正、两轮行为修订。只在保留原有全部公开通过项且增加通过项或恢复无异常运行时接受。按原三份实现的顺序取首份通过原四项准入和无异常的库，保留所有无效修改。所有配置、固定全开及空宿主按原协议部署二十题，改进和倒退均公布。独立操作在封存后运行。不会按正式分数挑选修复。
