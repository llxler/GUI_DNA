# 接收已经交付的编辑数组

公开轨迹修复的接收器要求外层为含 edits 的对象。GPT-OSS 的若干原答直接交付顶层数组，每个元素均有 file、before、after 三个原字段。使用同一个原接收器验证，只给数组补外层字段名；不改编辑项、源文件、模型或目标依据。登记时已检查过部分数组能精确匹配其请求所附的文件，尚未在浏览器测试这些数组改出的候选。

范围为轨迹修复后仍未准入、且有顶层数组交付的模型。核对原模型和收据摘要，按原库序号、修订轮、格式纠正轮与传输顺序重放。每份答复只对它实际收到的文件应用；读取公开初始检查、候选检查与宿主检查。通过条件为所有原先通过项保留、菜单可见、能插行、表外能关闭、选格可见且浏览器无异常。第一份符合条件的回复作为主库，保留先前所有被拒回复。相同候选只观察一次。这个阶段不重新请求补丁；若通过准入，新部署模型再独立选择全部二十项，并打分固定全开和无实现宿主。适用于同批共同目标的全部升降。预算 $0.50 仅供部署，连同其他阶段的已登记上限不超过 $20，付费截止不变。运行 `uv run python -m studies.browser_worker studies.webbench.table.model_modules.public_trace.array_reception.run`。
