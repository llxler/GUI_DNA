# 恢复模型自己声明的结构化模块接口

原设计约定每个模块说明共享 API。至少两款模型把字段写成按 API 名称分组的 JSON 对象；原接收器只接受单个字符串，导致多份完整设计在源码生成之前被拒。本阶段登记在旧阶段部署成绩出来之前。只对父阶段最终未建成库的模型执行，不改已运行成功的父库。全部使用父阶段原始需求、原模型、文件边界、公开检查、修复规则、部署与评分。只额外支持两个等价形式：非空字符串，或非空的结构化对象/数组；后者无损地编码为 JSON 文本交给原设计校验，不补写接口、不调整模块分工。每次独立建库按原顺序重放本模型对应种子的两个设计回复，核对请求与结算的响应哈希，接受首份能通过新接收器的设计。仍不可解析才用相同模型重新请求设计。三次均不准入则报告失败。原调用和新传输分别计费。

各模型对新通过准入的库生成全部二十份新方案，比较同题 Direct、固定全开、无实现宿主。此阶段以公开准入决定是否交付，主表保留最终失败的空白及实测低分。上限 $2.5，与本轮早期账本敞口、计算器并行账本上限和表格父阶段上限合计不超过 $20；截止 10:32 UTC。运行 `uv run python -m studies.browser_worker studies.webbench.table.model_modules.structured_design.run`。
