# 只用公开操作修复菜单交付与键盘事件路由

登记时首阶段仍在建库，本阶段尚未读取该阶段的任何官方分数。此前的 Table editor 属于开发项目。七个模型全部遵循同一条规则。先验收它们在上一阶段提供的库。未交付算缺测；未通过菜单、实际插行、表外关闭与点选的库，取上阶段最后一份自己的选区源码，只重做菜单。通过准入但右移、Tab、反向 Tab、编辑或删除仍有缺项的库，保持原菜单，针对键盘事件进行一次分工修复。规则固定于公开反馈，不看官方分数。

菜单回退由模型声明表头与表身各自的菜单项和 CSS 类，再为每项独立编写短函数，直接操作实际的表格和锚点。研究者提供通用菜单的显示、位置、范围匹配、点击转发与关闭。单测保留菜单声明和渲染但禁用全部动作的页面，以及完全空的起始页，量出这部分绑定的贡献。核心仍须通过与首阶段相同的四项检查且无异常；同一次核心最多再请求一次公开反馈修复。新准入的核心使用同一作者生成的键盘及其余扩展。

键盘事件发至 document。宿主按键名转发给三个函数，并传入实际 DOM 选区、焦点和该模型自己的 API；位移、范围和状态更新由模型写。反馈修复只依据实际操作。已有库仅接受保留原先全部通过项、无异常、且至少多过一项的实现；回退核心也须保持原通过项。对已准入的库，若键盘无改进或交付中断则保留原实现与原选择。新键盘覆盖原模块，绝不叠加两个监听器。其余扩展逐个接回，均需保留已有公开通过项且无异常。

源码与配置都未改变的库重用首阶段的选择，发生变化的库由同模型在实际观察过的累积配置间为 20 个目标重新选择。固定全开、空宿主、回退菜单壳单列。首阶段和修复阶段分别封存和报告，后者为预定报告协议，任何正式失分照录。新阶段独立账本最多 $2.90，两阶段最大预留合计 $9.90；新调用截止 14:25 UTC。运行入口为 `uv run python -m studies.browser_worker studies.webbench.table.shared_selection.event_routing.run`。
