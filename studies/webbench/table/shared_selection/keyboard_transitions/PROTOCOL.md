# 由原模型编写坐标与编辑状态转移

七个自建库均已通过菜单、插行、表外关闭与点选准入。此前若干编辑器能点选却不能用文档按键连续移动或退出编辑。此次为同一开发项目的追加诊断：已知前两阶段及部分正式成绩，不据此决定个别模型是否进入；七款均按前一封存全开页相同的九项公开动作检查。正式用例、报告、分数和参考实现不进入生成消息。前四个阶段的真实费用与早期结果独立保留。

在已有库上给目标模型一个只接收数据的函数接口。输入包含按键、修饰键、表格尺寸、实际选中格坐标和编辑状态；模型写移动、范围、清除、编辑四组转移。输出以选区、写入与编辑状态的通用补丁描述效果。研究者将坐标映射到 DOM，投影选区、执行文本写入和焦点切换，并保留原选区接口的状态。宿主没有每个按键的目标行为。旧键盘模块继续接收新函数未处理的事件。先在公开需求所规定的操作上用不同尺寸检查纯函数，允许同模型按失败样例改一次；再用原浏览器公开检查逐组接入，仅保留不丢原通过项、无异常的模块组合，最终整库必须至少多过一个原未通过的公开检查，否则沿用原库及实际逐题选择。测试时先尝试全部通过函数检查的组，再按固定顺序增量装配；不依据正式结果选择。

同一作者对改动后的配置重新逐题选择。另跑相同配置下的原实现、固定全开及空宿主；无动作菜单壳沿用原先的定义。原库无键盘模块时，新增一个可选键盘模块，与旧实现对照时该模块为空。源文件、配置和所有候选封存后再评分。新协议作为七个模型的汇总入口，接受全部已登记结果。新账本最多 $2，此前四阶段都已封存，以真实费用敞口计入总预算；新调用截止 14:25 UTC。运行 `uv run python -m studies.browser_worker studies.webbench.table.shared_selection.keyboard_transitions.run`。
