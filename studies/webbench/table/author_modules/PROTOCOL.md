# 用 GPT-5 自己写的模块重组表格库

使用已交付的三份同型号源码。第一份为原 GPT-5 完整表格库。第二份为 GPT-5 在 11 月 13 日只收到原库、公开需求与五个开发配置后自查的版本，修订了键盘、鼠标、拖拽与表格状态文件；排除另一个曾看到官方断言结果的 feedback 分支。第三份是 GPT-5 看到公开右键事件传播轨迹后返回的入口修订。所用代码均来自原作者，研究者只做不冲突文件的确定性合并。公开操作轨迹、宿主和组选边界由研究者提供。旧结果已知，这是开发过的项目。11 月 13 日的 GPT-5 计算器只按需求自查的修订与原库文件完全一致，另验证两份包的哈希、冻结接口和既有逐题配置，不假作新增模型调用。

表格交叉对照包括原始库、仅自查、自查前库加入口修订、以及同时采用两项修订的库。两项修订须没有文件交叉，编译器、模式与四种配置保持相同。先采用按登记排序的第一份轨迹修订；若四种配置中有任何一份无法公开打开菜单、插入行、在表格外关闭，就用第二份 GPT-5 轨迹修订从干净的自查库再建一次。两次均失败则报告失败。不会用官方得分选择修订。

七款主表目标模型均为每个当前任务新选一次配置。只显示当前允许的公开需求前缀、选项和库说明；四个后端共用同一份选择。固定首例也在全部二十题运行。所有候选封存后才评分。相同官方环境、任务号和完整文件哈希可复用既有浏览器回执。当前主表 GPT-5 列采用两项修订的首个准入库；每行必须在此前实际共同目标上全部有观察，任何失分照录。交付不完整的行保留此前协议，并标明新测情况。原部署、各对照及原建库费用分别保留。新 API 调用仅为部署，预算 $1.50；连同其他两项的完整上限与此前最高敞口为 $19.719928，付费截止 10:32 UTC。运行 `uv run python -m studies.browser_worker studies.webbench.table.author_modules.run`。
