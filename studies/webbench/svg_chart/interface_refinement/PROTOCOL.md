# SVG Chart 的 AI 库发布接口实验

2026-11-23。探索性假设来自既有 3/20 的图表组装结果。该库把完整实现与接口打包给规划器。把库作者已经写好的计划模式和两个示例单独发布，可能让规划器更容易输出可编译的计划。改动作用于规划阶段，继续采用 11 月 21 日 GPT-5 所建的同一个库，同样的编译器和公开起始工程。规划器从示例中读取原有描述和计划，若库有独立 plan_documentation 字段则原样加入。投影不复制 design、files、compiler。候选生成不读取人工实现、测试、评分或者前一次响应。

- 主要比较使用旧种子 20261123 的完整包历史记录，以及相同种子的新发布接口，对同一 20 个目标逐项配对。独立复验在种子 20261124 分别重新生成完整包和新发布接口两组，每组预登记同一 20 项，执行期间不修改提示词。仅新种子计为新的对照调用。任一比较均单独说明目标、收齐数、可编译数和通过数。
- 依原研究使用 Mistral Small 3.2、temperature 0.6、8,192 输出上限、JSON 模式、相同路由约束。公开需求前缀、起始工程、资产和系统消息逐字沿用原研究。输出直接作为计划，沿用原解析器、编译器和当前任务官方测试。任一收到的错误输出计方法失败，缺失响应单列未知。每个目标只提交一次；未知收费保留。官方评分要等全部本研究候选封存后开始。
- 先生成原种子新接口 1–20，再生成新种子两条件，按目标 1–20 提交，奇数先完整包、偶数先新接口。可同时有至多三个在途请求。当一笔新预留超出可用硬上限且仍有在途请求时，先等回执。已无在途请求且无法预留则记预算缺失，继续检查余下的目标。06:09 UTC 停止提交新调用。$0.08 账本独立，按保留额计敞口。费用不含历史建库和旧种子完整包。
- 两个种子的新接口都在相同 20 个有响应的位置严格超过各自完整包，才称该部署改动获得本项目两次确认。若不能补齐，报告配对已观察结果及缺失范围。任务文件共享实现，按任务列收益与退步，不将它们解释为独立测试样本。此实验不能验证重新建库的成功率、要求逐项重选的必要性，或对其他项目的推广。

本地入口为 `uv run python -m studies.library_refinement_chart.run freeze|generate|evaluate`。冻结原始提示、投影、来源哈希、校准和额度检查在独立目录 `artifacts/library-refinement-chart-20261123`。原始记录保持归档。
