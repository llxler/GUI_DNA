**固定页面。** 采用原 GPT-5 包自带的第一个示例计划。按数组位置预选，公开示例本来就可编译。用冻结的编译器编译一次，完整保留公开资产，对同一页面运行 20 份原官方当前任务文件。固定页没有读取任务前缀，所有 20 项使用逐文件哈希相同的页面。此项检验库本身与默认配置的行为覆盖。

**响应恢复。** 对已收到规划器响应的任务，先按历史部署逐字解析、编译；成功则保留其原页面，包括所有通过或未通过的页面。若响应无法解析或编译，则改用第一个公开示例。传输缺失保持缺失。触发仅取决于该阶段可见的格式/编译结果。记录任务是否触发，任务通过仅在候选封存后使用。此规则可用于任意有同类示例的库，不增 API 调用，不修改建库或规划器文本。
