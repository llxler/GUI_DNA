# SVG Chart 的 AI 库发布与恢复实验

以 11 月 21 日 GPT-5 冻结的同一可执行库、20 份官方当前任务文件为对象。闭源建库调用、规划调用及页面评分分别记录。公开结果为 [逐任务 JSON](../results/svg-chart-library-refinement-20261123.json)。

| 实验 | 配对目标 | 原部署 | 新部署 |
| --- | --- | --- | --- |
| 原始 20 个 Mistral 响应，解析或编译失败时使用首个公开示例 | 20，全部有响应 | 3/20 | 17/20 |
| 另一历史种子的五个预选里程碑，同一恢复规则 | 5，全部有响应 | 1/5 | 5/5 |
| 仅向 Mistral 发布模式与示例，原种子 | 20，1 项同时有响应 | 0/1 | 1/1 |
| 仅发布模式与示例，新种子下重新调用两种条件 | 20，0 项同时有响应 | 缺失 | 缺失 |

第一份公开示例固定页面在 20 项中通过 17 项。第一批恢复了 16 个无法解析的响应，增加 14 个通过项；第二批恢复了 4 个，增加 4 个。两批共用同一库及五个任务。库中已按公共资产上的类型分派六类图表，其公开计划配置主题、默认开关与文字。结果显示默认页已覆盖多数任务，后续逐任务规划的独立贡献仍需检验。

规划投影只保留作者的 `plan_schema`、已有的 `plan_documentation` 和两个原示例。供应商返回 9 次 HTTP 429，导致独立账本无法为后续调用预留上限。收到的 1 项为 task-7。该任务的新输出符合顶层计划结构，通过官方当前任务文件。验证整组改动所需的两组 20 对尚缺。历史库由 GPT-5 读取公开需求、起始工程、资产并经一次公开修复产生，本轮沿用其实现。新规划阶段账本已结算 $0.000293，包含未知预留的敞口 $0.078590，硬上限 $0.08。

[发布接口预登记](PROTOCOL.md) 与 [恢复实验预登记](RECOVERY.md) 分别冻结。离线审计可在项目根目录运行以下命令。

```bash
uv run python -m studies.library_refinement_chart.environment
uv run python -m studies.library_refinement_chart.run evaluate
uv run python -m studies.library_refinement_chart.recovery evaluate
uv run python -m studies.library_refinement_chart.report
```

评测器从评测目录启动，候选目录也需要继承上游的 ESM package.json。第一条命令在独立研究目录恢复原项目的包作用域。首次基础设施检查留下无测试执行的错误回执，修复包作用域后使用同一候选完成评分。固定页执行 20 次，两个批次的历史保留页分别执行 4 次与 1 次，另有 1 次投影新候选执行。26 次均获得官方回执。
