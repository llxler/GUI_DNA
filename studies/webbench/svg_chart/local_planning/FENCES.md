# 本地输出 Markdown 围栏的敏感性

首份本地精简包响应带单一 Markdown json 围栏。发现这一格式后，在后续批次及任何本地候选官方评分前固定下列敏感性规则；主实验仍按原协议要求整个响应是 JSON。这项补充不代表预先独立确证，也不改变原始回应、任务和分母。

只允许去除包裹整个响应的一对三个反引号，开头可标注 json；必须逐行单独开闭，其前后只能有空白。去壳后使用完全相同的强类型验证与编译，不纠正键、值、JSON 语法或自然语言。原来能直接解析的输出原样保留，缺失仍缺。对精简包和全包的各 20 个位置分别列出新恢复的有效计划数量、官方检验通过数、逐项变化及再回退默认示例的成绩。这一规则沿用了原有部署可解析 Markdown JSON 的做法，同时对开闭匹配和额外文本要求更严格。

评分前封存所有去壳后的页面与摘要。原脚本的同一官方测试文件、字节等同的既有候选可以复用回执。不得把这项检查的任何反馈重新送入规划器。
