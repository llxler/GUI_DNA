# 本地 Qwen 的完整包对照

2026-11-23。远程同模型检验因共享端点限流而缺失，增加一个独立的本地比较。研究在本地精简提示首项出炉后登记，在生成任何本地完整包候选前封存所有 20 个完整包输入和分析规则。

使用相同 Qwen2.5-0.5B-Instruct 检查点、原生模板、单样本贪心、768 新 token 上限、同一 20 个公开前缀与原 GPT-5 建库代码。完整包条件逐字采用早期 Mistral 所见完整消息。两条件的差别是计划接口之外是否一并提供 design、完整源码和编译器。比较指标与精简条件一致：原始响应作为严格 JSON 验证、编译并跑官方当前目标；独立记录仅在收到无效响应时回退到第一示例的结果。所有外部依赖、历史参考分数和官方实现都不参与模型输入。

在两批已登记的 SVG/table 精简接口本地生成结束后启动。逐个任务执行，06:06 UTC 关闭生成；超过 32,768 token 上下文（包含预留输出）的完整包输入不得裁剪，独立标为无法推理。未开始或未完成项计缺失。只在收到两份响应的目标上配对，分别报告共同分母、通过/退步位置及剩余取值范围。若未集齐 20 对，无整组确认；若集齐且严格接口下精简提示通过数更高，只能得出本地同一检查点与本项目的单次部署差异，不能外推到远程规划器。

原发布条件使用了 Mistral 的 JSON mode，本地规划器使用同一个原生文本解码器，未启用约束解码。两种本地条件使用完全相同的结构检查。这是出于供给中断而增设的探索性比较。
