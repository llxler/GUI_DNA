# 将文档作为文件管理器组件库入口

检查发现前一轮四份基础组件首个回复都是完整 HTML，公开任务本身要求保存为 index.html。原 JS 接收器将 Markdown 围栏当成 JavaScript 模板语法，浏览器启动后报错。本轮优先接收同模型同种子的首个原始完整文档，原样保留 HTML、样式和可执行代码，两个种子分开。若公开基础动作失效，可据实际浏览器反馈修一次完整文档。后续扩展必须由同模型另写唯一具名 installFeature(root) 或仅含脚本/样式的片段；不将整份独立页面伪装成扩展。只开放公开动作产生变化且保持已通过动作的扩展。固定页、基础页、空起始页及所有二十项仍全部评分。Direct 同样可接收原回复的整份 HTML，已有有效代码不改；Human 和 GPT-5 可接收原回复的首个完整 JSON 对象，但选择内容须经原编译器。不同来源使用真实任务交集。建库和规划剩余新增额度 1.50 美元，04:42 UTC 截止。
