# 文件管理器的同题库来源复验

固定 Web-Bench dom1 官方二十个当前任务；模型为 DeepSeek V4 Flash 与 Qwen3.5-9B。Direct 每题从同一公开 src-init 和截至该题的需求独立生成，可提交完整 HTML，不编辑前题。Human 使用由官方参考代码拆分的 44 个函数、原随任务声明的特征清单、原配置编译器与人工 CSS/布局适配器。GPT-5 使用 11 月 12 日已冻结、只见公开要求的第一个同名库及其原编译器，报告原建库成本；每题生成 JSON 方案。Self 每个模型独立建两份库，研究者只给静态模块顺序与一个空共享对象。语义开关、全部实际实现、选项效果由该模型书写；阶段内可据公开加载、增文件、增目录等观察修正，每个故障最多一次补源，两轮集成修复。披露向建库者提供全部二十项公开需求。A 为主，B 为重复；每份 AI 库测固定首例。同题检查资格一律在产生官方结果前冻结。
    
另以同一批部署模型给两份 11 月 23 日只看公开需求的 GPT-6.2 Astra 库选择其预登记可用配置，对照两份固定首例；不同建库者独立记录。所有组合保留失败和缺测。无交付时按实际共同目标给分母，不按分数选题。上游固定考题只在所有候选封存后评分。API 账本最多 2.50 美元，截止 04:42 UTC。公开组件与同题 Direct 均为本轮独立部署。
