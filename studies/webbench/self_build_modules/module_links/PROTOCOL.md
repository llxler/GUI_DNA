# 用同一模型已经写出的模块修复依赖

适用于 17 格中仍未通过公开准备的每个重复。只以该重复在源码接收修正阶段、第一次完成的模块包 v0 为起点。没有模块包就记录缺失。已准入重复不处理。旧官方结果、参考实现、其他模型或另一重复的源码均不得进入模型上下文。此前阶段采用过的公开操作不变。

静态读取提交的 ES 模块：若被引用的未绑定标识符在本库另外一个文件中只有一个顶层声明，补上该声明的命名导出和导入；若现有导入已经指定文件，且该文件确实声明所需名字，才补缺少的导出。记录每一次连接，不生成行为逻辑。编译并公开操作默认配置及首例。若仍不能启动，优先取实际不存在的本地依赖或浏览器堆栈定位到的源文件。允许同一模型根据自己现有源码、导入签名和公开诊断补交/改写该文件，最多两次。每次重新连接，首个通过候选即冻结，原库方案接口、默认和首例不变。同模型按原设置交付新的逐题配置，另评原首例。B 不能替代 A；真实零通过不移出主表。
