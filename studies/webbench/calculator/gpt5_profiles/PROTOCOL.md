# Calculator 的 GPT-5 建库与四模型部署

这是对新接口早期 HTTP 403 缺测的补测。使用普通 OpenRouter 端点按账户允许的路由请求 `openai/gpt-5`。不使用其他模型代建。建库沿用原[四组安装接口及公开验收](../behavior_modules/PROTOCOL.md)：只提供官方起始页、分组的公开需求与通用宿主，最多三次建库，每次最多两轮用公开观察修正，采用首份达标库并封存全部尝试。早期 403 记录保持冻结。新调用单独记账，本阶段上限 $3，整轮授权 $10、4 小时；停止付费调用采用更早的 15:05 UTC。拒绝或无回复按实际记录。

部署沿用 Self 的[十种可见配置和相同提示](../key_programs/PROTOCOL.md)。用新 GPT-5 库生成十个真实页面，先观察实际可见按键、模式与动作。Gemma 3 12B、Qwen3.5-9B、GPT-OSS-120B、DeepSeek V4 Flash 分别为 20 个目标选择一个配置，只看当前公开需求前缀与 GPT-5 库自己的目录。每个模型与主表已有的 Direct、Human、Self 逐题配对。主结果是该模型对新库所选的页面。另测固定全开及沿用同一模型先前 Self 选择的两个对照，均不参与主格选优。空白起始页沿用已封存的官方分数。所有候选与配置在开放官方评分前封存，保留每次交付、缺失、报告哈希和费用。每题仅评分当前任务文件。历史原生 JSON 接口的 10/20 单列。
