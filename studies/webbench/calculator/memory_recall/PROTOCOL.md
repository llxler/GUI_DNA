# 从真实显示值复验自建记忆键

公开需求要求 MR 把记忆值追加到已有显示。本阶段预先写出五个检查：非空显示上召回、连续两次存入再召回、存入后减去再召回、清零后召回、确认四个按键的相对顺序。起始页五项均失败，上游参考页五项均通过。用同一组公开交互检查四款此前已封存的 Self 完整页；Gemma 缺全部记忆键，其余三款五项均通过。仅对未过五项的库安排补建。已知这些项目的历史分数；本阶段给模型的证据只有公开需求与上述公开观察。注册不含官方测试源码、参考页源码或正式失败记录。

从该作者首份记忆声明读取已有的按钮顺序和面板名。分别询问每个按钮按下后显示值和记忆值的单个表达式，不要求小模型同时输出完整键盘、文件或双寄存器 JSON。平台安装和读取状态，不提供运算。准入要求保留此前的所有公开检查，并通过五个新交互，失败则回到原页按顺序重建，最多三次。复用原二十个配置，省去新的目标选择。独立数字、原实现、固定全开、恒等运算和空宿主单独记录。对数值不变或下降的情况按相同规则报告。新增上限 $0.50，与并行阶段的全部上限合计不超过 $20，沿用 10:32 UTC 截止时间。运行 `uv run python -m studies.browser_worker studies.webbench.calculator.memory_recall.run`。
