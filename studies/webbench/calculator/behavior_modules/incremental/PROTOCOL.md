# 小模型按先后两段实现行为

父阶段四份 Self 首库都能加载。公开检查满分 15 项；低于一半的两款模型为 Gemma 12B、Qwen3.5-9B。前者多次返回错误的函数声明，后者早期与完整开关走了互斥分支，使已实现的基础科学键在完整版消失。只按公开检查选取这两款模型。两款其余模型保留父阶段首库，全部使用同一既有二十题方案。本协议在该阶段正式结果生成前登记。不会根据正式成绩决定是否呈现。

每组由同一模型生成前后两个 JavaScript 函数体，后段只读该模型自己的前段和当前公开变更。早期档安装前段，完整档依次安装前段、后段；不会用后段覆盖已有前段。研究者提供与父阶段相同的按钮/显示值接线及四个模块边界，把每组公开需求拆成前后两段。模型实现全部新增行为。只接收函数体或无歧义的外层函数，不补写任何语句。出现语法错误可用原作者修一次。实际浏览器公开动作同时记录键名、可见性和计算结果。按组最多再修正两次，接受时须保留已通过的动作并增加至少一个。关闭全部模块必须保留十键和基础加法。首份包含所有此前已通过的公开动作、通过至少一项此前失败的检查、具备开关可移除科学能力的完整库准入；不达标使用新会话从头重建，上限三份。若仍无新库通过，明确记录全部失败，再用阶段开始前封存的可用库按原方案部署。原正负结果分列，官方分数和源码始终不传回作者。

公开动作更换操作数的复验、二十个官方文件、固定全开和无组件对照分别报告。新发生的 API 费用均为这两款模型的建库或公开修正；没有重新选择逐题方案。独立上限 $2.50，在父阶段和 GPT-5 交付账本停止新增请求后计入实际敞口，表格研究并行仍预留其完整上限。沿用同轮 $20 和 10:32 UTC 截止时间。运行 `uv run python -m studies.browser_worker studies.webbench.calculator.behavior_modules.incremental.run`。
