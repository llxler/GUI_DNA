# 计算器两种新增目标模型

沿用 11 月 26 日按键分组协议，在首次生成前登记 Gemma 3 12B 与 GPT-OSS-120B。前者是主表中已有的小模型，后者是较大的开放权重模型；两者都尚无本协议的计算器行。每个模型部署同一批 20 个官方当前需求。Direct 使用起始工程和需求前缀。Human 使用参考 HTML 和五组人工标注的按键；GPT-5 使用先前冻结的 GPT-5 库。Self 由该行模型分别建库两次，只看完整公开需求及自己的公开按键检查。主表固定用第一库，即使第二库得分更高也不替换。首库未通过公开检查留空，未取得输出保留缺测；合法库部署的无效输出计失败。合法且有观察的方法取共同目标，逐题公布。另列起始页、各库固定页和关闭可选组的成绩。此处不运行 Astra 的额外比较。
