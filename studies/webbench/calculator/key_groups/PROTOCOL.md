# Web-Bench 计算器的跨来源比较

先登记 Qwen3.5-9B 与 DeepSeek V4 Flash，各二十个当前文件。Direct 用官方 src-init 和截至当前的需求独立写网页；同一模型的 Self 见完整二十条公开需求后独立写两个完整 HTML 文档，并根据自己实际写的按钮登记至多六组可配置键。宿主只按库声明选择哪些控件显示，不实现算术。基础数字、四则运算、等号和清空键不得屏蔽。每套库必须用鼠标验证 2+3=5、至少一个模型声明的可选按键能生效，且关闭组会移除相应控件并保留四则运算。若入口不通过，可基于同一公开动作修复一次。

Human 使用上游 src/index.html 原样保留的行为、样式和初始状态，由研究者分出幂与倒数、常量、三角、双曲、记忆五类可见按键；此参考实现可见完整应用。两种来源均测实际配置、全开、关闭所有可选键和官方起始页。公开的起始页已经实现基础运算，单列其通过数。另用 11 月原始 GPT-5 库、两份独立 GPT-6 Astra 库及各自首例，注明准备花费。三个外部库沿用其真正的原编译器。规划只见前缀、接口与选项。直接生成响应与自建入口均可接受原样 HTML 或单文档包，按实际交付保留非法与缺测。

首库 A 固定为论文组，第二库及强库在可复核记录中单列。两个模型全部候选封存后才执行任何官方任务，使用上一轮冻结的官方浏览器协议。共同目标齐备的四个方法在主表 A 的相同四列公布。本阶段预算 2.50 美元，最迟 04:42 UTC。
