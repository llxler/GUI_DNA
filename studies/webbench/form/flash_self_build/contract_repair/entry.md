# 将完整 ES 模块交付到公开入口

针对同一份 Flash Delivery B 的收窄后公开加载失败，登记最后一项纯封装修正。浏览器原报错为 Cannot use import statement outside a module。公开起始 HTML 从 ./index.js 加载模块；模型把包含静态 import 的完整入口交在原组装器解释为 classic script 的字段中，所交文件不含 index.js。

从原起始页读取唯一 type=module 外部 JS 入口，并要求旧注入脚本含原生静态 ES import。将起始入口的原字节、一个换行以及模型 script 的完整原字节顺序写入该磁盘入口，清空 classic script 字段。保留收窄后的合法域、原 controls 所有其他字段、首例、HTML、样式与原来所有模块字节。登记并报告整段入口的旧新摘要、拼接偏移和保留下来的原模块摘要。没有生成、补写事件处理器或修改任何模型代码。

仍按原验收编译默认与首例，再让同一 Flash 在原设定下逐题配置，最多 20 笔原目标请求、零建库请求。A 复用，无库、人工和 GPT-5 使用原始观察。包括先前所有失败分支在内，全部候选封存后才评分。此诊断可支持正在研究的同模型代码交付；不把同一 B 的层层包装认作独立建库重复。
