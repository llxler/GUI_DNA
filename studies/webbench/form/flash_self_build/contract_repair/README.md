# 问卷 B 库的公开交付修复

DeepSeek V4 Flash 在 B 中已交付 11 份模块和一段完整入口代码。初始接口有两个超长枚举，整包在公开检查时被拒。下表的 B 行均通过同一份模型响应派生，按同一批 20 个官方当前任务核验。模型、起始页、目标与规划设置保持一致。

| 条件 | 公开准入 | 逐题配置 | 固定首例 |
|---|---|---:|---:|
| 重用独立 Delivery A | 成功 | 12/20 | 12/20 |
| B，仅让模型回复较短的选项列表 | 仍返回 9 项和 11 项 | 0/20 | 0/20 |
| B，程序仅缩短两个选项列表 | 入口的静态 import 在经典脚本中加载失败 | 0/20 | 0/20 |
| B，另将同一入口迁移到原页的 ES 模块位置 | 成功 | 14/20 | 14/20 |

最后一步保留原起始入口前缀、3654 字节模型入口、十一份模型模块；旧入口与迁移后子串的 SHA-256 相同。规划器可选域中，最短长度少一个值 7，NPS 少三个值 6、8、9。B 首例与逐题配置通过完全相同的 14 项。现成 GPT-5 库在同题上通过 13 项，B 独过任务 9、11、16、20，GPT-5 库独过 6、10、14。从零对照为 4/20，人工库为 17/20。补充总费用为 $0.033885，无未结费用。A 复用原费用与官方收据。上述 B 修复在获知公开错误后设计，独立重复须另行前瞻登记。
