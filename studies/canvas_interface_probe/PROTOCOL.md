# canvas 公开行为诊断

只用公开 task-17 的交互合同。此诊断在检查候选隐藏成绩、查看模型库之前确定，绝不将结果用于修复或选库。每个重复的冻结库取两个作者示例；另外从示例 0 出发，逐个顶层字段替换成示例 1 的值（包括省略），保留合法方案和拒绝原因。两个示例可能相同；这只检查上述有限切片。用各方案重新编译，记录源码哈希；相同输入源码精确复用浏览器观察。

固定 Chromium、视口 800×800、随机种子（1、2、3）和模拟时钟。点击 canvas 开局后，分别在独立、新建的相同页面按游戏规定的 k 或对照键 z。记录按键前和之后约两帧 window.store.bullets 的长度。两键的差分要求 k 使数组增长、z 不增长；缺少 canvas 或可观测数组单列，不能等同于无反应。同一个库中，若只有一个顶层配置值变化，两种有效配置对这项差分在三次种子下均得出相反结果，即为局部行为见证。报告其他观察及覆盖边界。官方参考和空白先做同法校准。此处只测公开开发行为，和官方 task-17 文件及主试验分数分别报告，不重启模型调用。
