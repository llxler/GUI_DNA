# canvas 固定页面复用诊断

生成期间（查看主候选成绩之前）为两次独立建库预定三个固定页面。对每套库原样编译示例 0、示例 1，并取该次 GUI-DNA 的 task-20 最终页面。把每张固定页面分别送入五个里程碑各自的当前任务文件。前三者按预定名称逐项呈现，不挑成绩最好者。每个重复、每个控制各有五次比较，与同重复逐目标 GUI-DNA 逐项对照。末任务页面使用 task-20 输出，是事后可获得的复用对照；示例在建库时即已存在。控制无额外模型调用。

主实验全部生成/评分完毕后才执行。若页面完整文件和同编号测试与已有评分完全相同，按初始工作流遍历顺序复用首份原报告并登记来源；若已有相同页面重复判定不一致，报告冲突。其余独立运行单个官方当前文件。缺页与缺失原因单列；所有结果单独记录，无控制覆盖主成绩。
