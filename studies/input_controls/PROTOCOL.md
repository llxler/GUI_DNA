# 官方判据对缺失输入行为的敏感性

选择依据为公开需求。canvas 只拦截 k/K 键的 keydown、keypress 与 keyup，对应公开 task-17 的射击行为；flex 在按住鼠标时只拦截 mousemove 和 pointermove，对应窄屏 task-20 的拖拽缩放。每项目以 task-4 作为预定的无关目标。每个文件分别独立评分。此诊断不使用模型候选，不更改官方文件、模型成绩或生成输入。

每项目以官方最终参考实现生成三个页面：原版、在同一位置注册空监听器的对照、注册拦截监听器的版本。记录源码、控件、公共观察和官方评分哈希。先用独立的公共交互确认干预是否生效：canvas 用原定三组种子比较 k 与 z 产生的子弹增量；flex 在宽 360 高 720 的浏览器内用右侧拖柄上下各拖动 40 像素，观察内容高度是否变化至少 2 像素，在全新页面重复两轮。只有前两种页面显示行为、干预后对应行为消失时，才可解释该行为的官方判据敏感性。若官方文件仍通过，记录明确的漏检；若失败，记录对本次干预敏感。无法确认干预的项目保留原始数据并记为不能推断。各项目报告关联文件与无关文件，不汇总为覆盖比例。
