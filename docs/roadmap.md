## 0. 当前审稿问题与优先任务

- [ ] **P0：完成预算与信息匹配的端到端实验。** 现有建库者看过全部 20 条公开需求，基线只看目标累计前缀，且没有等量构建调用。当前结果支持两条工作流比较，不能归因于组装形式本身。按 [预备协议](end_to_end_protocol.md) 冻结公开项目、完整输入、总预算、重复次数、终点与失败处理后再生成。先做一个独立公开项目的小批次，核对实际费用后扩展；本轮尚无新增付费授权。
- [ ] **P1：补足独立项目、强模型和重复。** 保留全部建库失败与首次有效库，不按隐藏成绩选库。GPT-5 三项目旧小试没有无库组，不能借用其他模型结果当基线。新项目不得由隐藏成绩选择，不混合三套旧协议的分母。
- [ ] **P2：确认接口能改变行为。** 核对组合是否改变编辑、删除、筛选等交互，而非只有主题/字号；检查只能用预定公开开发行为。固定页面/配置可作为独立诊断；不要把整体收益直接叫作抽象学习或规划必要性的证据。
- [ ] **P3：全流程费用与复用次数。** 一次建库费＋各目标生成/修复费，对比无库实现的总费用；同一累计需求与同一总限额下报告收益，保留失败建库和未知预留。补建库/维护人时的前瞻记录，不能从公开数据集资料推算过去工时。
- [ ] **P4：官方断言的剩余覆盖核查。** 已定位 BOM 六文件空过；统一排除后，无库 39/108，GPT-5 建库 43/108、Claude 建库 36/108，改善方向不同。补有信息增益的负对照；诊断与官方成绩独立，不修改旧断言或回填。
