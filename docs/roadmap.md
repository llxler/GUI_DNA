# 研究任务清单

当前论文比较 AI 根据公开需求建库后用 GUI-DNA 组装，与无库模型从零写页面。主指标为对应的官方当前任务文件。已完成的匹配实验、行为诊断和复验见 [实验记录第 38 节](results.md) 与 [报告视图](../studies/results/end_to_end.json)。旧任务见 [归档](archive/roadmap-20261117.md)。

## 0. 仍决定论文结论的实验

- [ ] **P1 扩大独立应用覆盖。** canvas 和 flex 各只有五个里程碑、每种设置两次准备。按公开清单预定下一个独立应用族，并在看成绩前确定样本量。Claude 目前只在 canvas 匹配设计中测试；保留两组相同的真实目标。按项目、模型、重复分别报告。
- [ ] **P2 找到哪些需求确实需要换方案。** 将已观察的行为切换与公开需求之间的冲突对应起来。先固定两个需要不同响应的目标及固定页对照，再看相同库的两个方案能否各自满足对应要求。已有单字段浏览器测量只能支持所测交互。沿用官方当前文件评分，诊断与官方成绩分开。
- [ ] **P3 检验更长复用周期和人工开销。** 现有五目标顺序已经包含实际准备、失败和修复。下一批在开始前记录维护和人工操作时间，在更长的目标序列上同时报告通过数与费用。不同建库者分开，不从公开数据集推算旧工时。
- [ ] **P4 扩展剩余断言审查。** 除已记录的 BOM 空过、canvas 射击与 flex 窄屏拖拽外，优先检查参考界面可做但旧候选普遍失败的行为。用已知具体缺陷和空操作对照验证判据的区分能力，维持原断言和原分数。

## 1. 论文与公开交付

- [ ] **R1 作者审核。** 复核论文结论、引用、署名与 AI 使用披露，确定匿名审稿链接。
- [ ] **R2 跨机器复验。** 当前报告包已在本机另行解包复算；在干净机器上重新安装锁定依赖、验证两个入口并重跑浏览器抽样，登记环境与差异。
- [ ] **R3 公开材料授权。** 审核仓库自身许可证、上游及生成资产分发边界，确定原始产物可获取范围与匿名托管方式。保留旧路径兼容和冻结证据。

执行新实验前查看 [操作规则](../AGENTS.md)，先冻结协议与输入，再生成、评分并记录全部失败和费用。已关闭的实验不续跑。
