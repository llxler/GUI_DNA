# 从界面生成论文到 GUI-DNA 的实验问题

## 指定论文 LaTCoder（KDD 2025）

Gui 等人先给出一个肉眼可复核的横竖排列错误。生成页保留了部件，却把横排变成竖排（图 1）。作者将任务限定为从设计图生成静态 HTML/CSS，并让切分后的每个图块携带原图坐标，供组装页面时使用（第 2–3 节）。第 5.2 节拆开比较绝对定位和模型组装，前者在像素误差上占优，两者在若干其他指标上接近。第 5.4 节再区分块内排版错误与组装时遗漏整块。文中对齐的是渲染布局，未以用户操作后的状态作为评估对象。[用户提供版本的论文全文](https://arxiv.org/html/2508.03560v1) · [KDD 论文](https://doi.org/10.1145/3711896.3737016)

我们的引言据此从文件管理器的四次点击写起。两种方法都创建四个条目，观察父子关系才能看出差异。这样可以具体说明应保留什么信息（当前选中项），以及哪些控件共享这个信息（新建文件、新建目录）。比较组装方式时还要追问，同一库里换方案是否真的多通过了某个目标？若同一保存页已通过逐目标方案所过的文件，就记录它具体覆盖哪些文件。[人工库协议与数据边界](method.md) · [匹配实验记录](results.md)

## 五篇直接评估交互生成的工作

| 论文 | 引言如何界定任务与状态变化 | 如何测量，对 GUI-DNA 有何启发 |
|---|---|---|
| **Interaction2Code**（Xiao 等，ASE 2025） | 从静态商品页转到选尺码、改数量等操作。交互原型给出动作前后的页面视图。 | 执行生成页中的动作，再评估变化区域；另有人审。GUI-DNA 的文件树例子同样要指明观察位置，但任务输入是文字需求，生成器看不到期望的结果图。[论文第 1、3 节](https://arxiv.org/html/2411.03292v2) |
| **WebApp1K**（Cui，2024） | 从通用代码题转向可执行的前端组件。文中的评论功能给出输入、点击和提交后的预期结果。 | React 测试同时进入生成提示与评估。GUI-DNA 必须区分研究者准备组件时接触的测试信息和模型为某一目标生成答案时能看到的信息。[论文第 1–3 节](https://arxiv.org/html/2408.00019v1) |
| **Web-Bench**（Xu 等，2025） | 从独立编程题转向持续实现功能的项目。一个任务可以扩展已有行为，要求和上下文取决于它在项目中的位置。 | 官方设计含 50 个项目，每项 20 个顺序任务，以端到端测试检查功能。我们的结果要保留项目和任务位置、注明旧文件管理器基线编辑前一页，并把通过范围限定为当前文件。[论文第 1–3 节、附录 A](https://arxiv.org/html/2505.07473v1) |
| **WebGen-Bench**（Lu 等，NeurIPS 2025） | 从修补现成仓库转到按产品描述新建多文件网站。把「功能可用」落实为在站点里执行操作后应出现什么。 | 导航代理执行操作、判断观察结果与预期是否一致。我们用既定浏览器断言判定，并逐项交代无库生成收到的需求、起始文件和准备机会；两项工作的通过率单位不同。[会议论文](https://proceedings.neurips.cc/paper_files/paper/2025/hash/6841eed8bb6a2ec49e49235c8115efee-Abstract-Datasets_and_Benchmarks_Track.html) |
| **AppForge**（Ran 等，ICLR 2026） | 从生成单个函数转向根据需求实现 Android 应用。多个组件要在状态变化、生命周期与异步操作中配合。 | 作者从已有应用提炼规格并构建交互测试，再由 Android 专家复核。GUI-DNA 可借鉴其从组件协作引出可执行问题的方式；我们的分母是当前网页任务候选，不能解释成完整应用或移动端通过率。[会议论文](https://openreview.net/pdf?id=XrP8dp1rCg) |

## 本稿据此采用的证据口径

- **组件是否可用。** 标明来源，以及准备者是否见过测试或参考实现。对照组得到什么，随每种协议单独交代。保留从零写各目标和编辑前一页的区别。
- **模型能否正确绑定。** 同一个冻结库存在通过的配置，生成方案却失败时，可以定位到所测生成流程。若只有若干失败配置，仍无法判定库内所有配置均失败。
- **目标是否要求重新选择。** 对照同一固定页与各目标方案通过的具体文件。一次按键能改变速度，只能证明该设置确实改变所测交互。要证明不同目标必须采用不同方案，还要排除其他固定配置能同时过关的可能。
